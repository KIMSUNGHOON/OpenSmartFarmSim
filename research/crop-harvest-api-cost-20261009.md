## 작은 조립 수용

- 최종 집중 원42829 종료0·40개(새 TLS/loader11·기존 HTTP 대사29)를 통과했다.
  실제 TLS에서 전체 요청 마감·느린 header/분할 body·2MiB 초과·잘못된 CA와 실패 시 FD 정리를 검사했다.
  frozen source의 절대 경로를 선택하고 이미 적재된 다른 backend를 거부한다. namespace package의 다른 checkout 경로도 제거한다.
- 실제 원 부모의 정상 작은 수확5행을 보존한 후 표준 `ApiRuntime`/같은 농장·jobs/실제 SCRAM DB에 정상 reader factory를 조립했다.
  원400 보존 key/config를 바꾸지 않고, 별도 소유600 운영자 설정에 같은 key bytes를 복사했다.
- 원77863 실제 종료0/68.444초의 HTTPS7응답에서 summary·첫5/끝1·복원 summary와 다른 tenant404/scope403/표시권422를 확인했다.
  원 저장 ID/최초 UTC·summary/page SHA·원량과 독립 ASGI/실제 wire의 bytes·SHA가 일치했다.
  최대19.984초/49,835bytes로30초/2MiB 안이다. 공유 권리/계정 파일 변경은0회다.
- 조회 RHS/수확 생성/등록/증명0·DB count/원본1,195항목·FD3→3을 보존했다.
