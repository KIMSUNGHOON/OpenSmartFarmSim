# 호출자가 선언한 잎 제거의 1차 근거 — 2026-10-24

상태: **합성 소프트웨어 장부의 다음 작은 경계에 대한 출처 검토**. 적엽 시기·자연 노화 예측,
Axiany 계수/실측·탄소/생산량 모델 채택 또는 G0–G4 판단이 아니다.
[토마토 기준 조사](crop-tomato-model-baseline-20261004.md), [phytomer 분류](crop-phytomer-kind-20261023.md),
[기존 population v1](../contracts/crop-leaf-population-v1.md)을 읽었다. v1은 독립 제거를 거부하며
현재 목록 1–512개를 요구하므로, 제거는 기존 판본을 바꾸지 않는 별도 계약의 검토 대상이다.

## 실제 조사 실행

native Codex CLI 연구 자식 `/root/declared_leaf_removal_sources`의 실제 `spawn_agent` 선택은
`model=gpt-6.1-sol`, `reasoning_effort=xhigh`, `fork_turns=none`이다. 도구 응답은 호출 timestamp를
노출하지 않았으므로 미확인으로 둔다. 재귀 CLI 호출·추가 자식·외부 연락은 없다.
대조자는 이 연구 자식이며 독립 자료 승인 reviewer는 없다. 부모가 최종 도메인/설계 판단을 수행한다.
README의 범위와 PROJECT_SPEC/RESEARCH_BASELINE의 근거·권리 경계를 따랐으며 원 자료를 채택하지 않았다.

## 합성 계약으로 정당화할 수 있는 범위

아래는 **이 프로젝트의 검토 가능한 소프트웨어 정책 제안**이며 원 논문의 구현을 재현한다는 주장이 아니다.
부모의 별도 판본/불변 이력/빈 현재 목록 제약을 검토 대상으로 반영했다.

1. 호출자가 기존의 안정적인 잎 ID와 명시적인 정확 사건 시각·선언 provenance를 제공한다.
   선택 순서·관리 필요성·노화 원인은 추정하지 않는다. 첫 경계는 추적 중인 전체 잎의 제거다.
2. 사건 시각까지 해당 잎 면적을 기존 명시 forcing/시계로 전진한 뒤 현재 목록에서 제외한다.
   사건 직전/직후 면적 수지는 `A_active_after = A_active_before − A_removed_at_event`이며 모두 `m2_leaf`다.
   이 식은 장부의 항목 합계 관계이고 새 생물학적 계수나 탄소식이 아니다.
3. 원 초기 anchor·출현 선언/`birth_inventory`를 지우지 않고 제거 선언·시각·마지막 상태를 보존한다.
   제거된 ID의 재사용/재성장으로 중복 면적을 만들지 않는다. 현재 잎이 0개인 상태는 별도로 명시한다.
4. 미존재/이미 제거된 ID·시계 불일치·범위 밖 사건은 보류/거부한다. 동시 출현/제거와 끝점 포함 규칙은
   계약에서 명시해야 하며 원문에서 얻었다고 주장하지 않는다. 동일 시점 분할 재개에서도 중복 제거가 없어야 한다.

면적 합계나 감소량을 SLA로 나누어 탄수화물·건물·생과중으로 자동 변환하지 않는다.
바닥 면적·식재/줄기 밀도·개별 기관 질량·해당 조건의 변환/배분 정책과 별도 수지 검증이 없는 상태에서는
집계 작물 탄수화물 원장과의 결합을 보류한다. 빈 현재 목록도 LAI·광합성·생산량 0의 자동 근거가 아니다.
이 단계에서 주장할 수 있는 결과는 **명시 사건 뒤 추적 중인 잎 수·면적의 결정적 장부/재생**까지다.

Vanthoor PDF와 GreenLight JSON/라이선스의 새 bytes는 기존 조사 SHA와 일치한다.
새 diaf022 PDF는 기존 HTML/보충 PDF와 **다른 객체**이므로 그 hash를 재사용하지 않았다.
PDF header·본문의 해당 절·단위를 직접 읽고 SHA-256을 계산했다. 이는 출처 동일성/QC 대조이며,
농장 측정의 정확도·개별 제거 관측의 QC 또는 입력 G0 승인이 아니다. 제한 원문은 저장소 밖에만 보존했다.
출판사 본문 native 요청은403, 브라우저 DOI/재조회는500 등으로 실패한 경로도 있었다.

이 작업의 저장소 변경은 이 문서 하나다. 구현/제품·수치·브라우저 시험은 실행하지 않았다.
소프트웨어 검증 후보는 사건 직전/직후 면적 대사, 마지막 잎 제거, 중복/미존재 거부와 분할 재개의 동일 이력이다.
실제 적엽/자연 노화·Axiany/국내 독립 작기·탄소 수지 결합·수확/자원/경제와 관문은 계속 별도 보류다.
