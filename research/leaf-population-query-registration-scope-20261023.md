## 실패와 보류

기존 native HTTPS 정상 시험은 **첫 인증 접수 POST**에서30초 `TimeoutError`로 실패했다.
leaf GET endpoint에 도달하지 않았으며 이 admission 소스는 변경하지 않았다.
실패를 보존했고 동일 POST를 다시 반복하거나 timeout을 늘리지 않았다.
뒤의 HTTP 취소/늦은 변경2시험은 이번 판본에서 실행하지 않았다.
이전 실제 계산 중 동일 retry의30.028101초/504도 별도 보류다.
따라서 HTTP 전체·runtime 부모·새 계산의 자동3D 경로를 완료하지 않는다.

첫 별도 HTTPS probe는 backend 전용 snapshot에 없는 시험용 readonly 모듈 import에서 종료했다.
HTTP 시작 전이며 원 DB/파일을 보존했다. 시험 모듈 검색 경로만 보완한 다음 실행이 위7응답이다.

모든 집중 단계에서 원 사용자3root·감시2,481항목과 소스 고정을 확인했다.
정상 집중 시험의 합산 최대 RSS는611,356,672bytes이며 소유 잔류0·감독 FD4→4다.
단계별512MiB/합1GiB·600초·로그4MiB와 실제 HTTP30초/2MiB를 유지했다.
전체 backend/새 hosted CI는 실행하지 않았다. 웹은 변경하지 않았으며 기존 웹 CI39925213943의
성공을 이번 backend 시험으로 계산하지 않는다.

판단은 현재 native CLI `gpt-6.1-sol`/`xhigh`의 기록으로 남겼고 재귀 CLI 실행은0이다.
합성 소프트웨어 증거이며 실제 품종/독립 작기0, G0–G4·생산/자원/경제·자율 선정과
최종 사실감 R2/첫 shader 경고는 미수용이다.
