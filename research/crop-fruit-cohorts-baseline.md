## 식과 상태 대조

`N_j`는 구획 j의 **연속적인 모델 과실 수/면적**, `C_j`는
**mg CH₂O/면적**이다. 실제 개별 과실의 정수 개수/모양/색이 아니다.
소프트웨어 연구에서는 면적을 `m2_floor`로 명시하며 실제 원천 분모 채택은 보류다.

| 원 식·인쇄 페이지 | 확인한 계산/의미 | 첫 구현/남은 조건 |
| --- | --- | --- |
| 9.2/9.3, p244–245 | `dC_j = A_j + K_(j-1) - K_j - M_j`; `dN_j = S_(j-1) - S_j` | 기관/개수 보존 경계. 탄소 첫 구획의 이전 이동은 0, 개수 첫 유입은 착과 |
| 9.29/9.30, p253 | 과실 set은 전체 과실 탄소 유입에 따른 piecewise 비율 × `nPlants*(cSet1+cSet2*T24)` | 실제 밀도/개화·착과와 초기 seed, 평활판 선택은 보류 |
| 9.31/9.32, p253–254 | `S_j = nDev*rDev*h*N_j`, `rDev=cDev1+cDev2*T24` | 첫 순간 이동은 원 piecewise h=1인 생식기 범위로 한정 |
| 9.33, p254 | 온도 합이 onset 이하이면 h=0, 초과하면 h=1 | 식 옆 s⁻¹ 표기는 설명의 무차원과 충돌. h를 무차원으로 대조; 평활 B.1/Table9.2는 별도 정책 |
| 9.34, p254 | `K_j = nDev*rDev*C_j` | 이 식에는 h가 없다. 첫 지원 범위 h=1에서는 개수/질량 이동률이 일치. 생식기 이전을 같은 이동률로 임의 변경하지 않음 |
| 9.35, p254 | `A_1 = W1_potential * fruit_set` | W1의 Gompertz 적분 경계/초기 질량 정의가 명시되지 않아 보류 |
| 9.36/9.37, p255 | 뒤 구획에는 `(F-A_1)*N_j*GR_j/denominator`, j≥2. 인쇄 분모는 j=1부터의 합 | 아래 보존 반례. 전체 배분은 미채택 |
| 9.38–9.42, p255–256 | Gompertz 미분·FGP·구획의 대표 나이 | 값/단위 근거는 확보. 품종의 잠재 과중·적용성/초기조건과 결합은 보류 |
| 9.43–9.45, p256 | 성장 호흡은 buffer에서 한 번, 유지 호흡은 각 기관에서 차감 | 후속 결합에서 기존 fruit 유지 호흡과 구획 호흡의 이중 차감 금지 |
| 9.7, p245 | 마지막 구획 유출 × CH₂O→DM 계수의 연속 연구 수확 | 생과 kg/실제 수확 사건·등급/판매가 아님 |

FGP는 `1/(rDev*86400)` day, `M=-4.93+0.548*FGP` day,
`B=1/(2.44+0.403*M)` day⁻¹, 대표 나이는 `(j-0.5)/nDev*FGP` day다.
`GR_j=GMax*B*exp(-B*(t_j-M))*exp(-exp(-B*(t_j-M)))`는
mg CH₂O/fruit/day다. 계산 시 day와 second를 구분한다. 이 식을 전체 수확
시각의 엄격한 지연으로 해석하지 않는다. boxcar에는 분포와 작은 초기 유출이 있다.

### 실제 원식의 보존 문제

PDF p255의 분모는 `D=sum(j=1..n, N_j*GR_j)`다. `w_j=N_j*GR_j`이면
인쇄식을 그대로 쓴 총 배분은

    A_1 + (F-A_1)*(D-w_1)/D = F - (F-A_1)*w_1/D

이다. `0<A_1<F`와 `w_1>0`이면 F보다 작다. D=0에서는 정의되지 않는다.
이는 **대수적 대조로 얻은 판단**이며 저자 승인 정정이나 실제 작물 손실이 아니다.
분모를 j≥2로 바꾸면 보존이 되지만 원식의 정정·새 모델 판본 결정이 필요하다.
그 수정이나 남은 탄소를 buffer로 되돌리는 규칙을 조용히 넣지 않는다.
`crop-fruit-allocation-policy`에서 원 구현/추가 근거·원/수정식·초기/빈 sink 정책·
독립 참조를 검토한 뒤 별도 판본으로 수용한다. 첫 이동 계산은 F/A_j를 사용하지 않는다.

## 권리·검증과 다음 한 단계

원 학위논문은 수학적 정의의 연구/인용에만 사용한다. PDF/그림 재배포 권리는

모듈로 검증하고 미확인 외부 재구현/플랫폼 의존성을 추가하지 않는다.

이번 수용은 원 PDF 해시·직접 식/표 대조, 코드의 실제 50구획 부재와 초기값 차이,
차원/보존 문제·필수 입력/계수·검증 계획·보류를 명시한 **명세/조사 수용**이다.
새 작물 수치 계산/fixture/Run/G0–G4 검증은 없다.

다음 `crop-fruit-transport`는 50구획의 순간 `dN_j,dC_j`·마지막 유출·두 수지와
model/profile/input hash를 표로 확인하게 한다. 독립 Decimal 원식 참조(17/20/23°C,
0/첫 구획/다중 구획), telescoping 수지, 음수/비유한/불일치/영역 밖·입력 불변을
검증한다. 기대값을 제품 함수로 생성하지 않는다. 시간 적분/사건·자원/생과/경제는
뒤 단계다. 코드 파일·프로필·독립 fixture를 작은 묶음으로 만든다.

조사 계약은 2026-10-05 KST에 완료했다. 순간 이동 모듈은 고정 식과 계수,
