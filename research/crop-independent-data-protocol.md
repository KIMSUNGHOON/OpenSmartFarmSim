## 대상과 자료 접근

첫 개발 참조는 Axiany/Maxifort 한 해외 작기다. 국내 후보 농장이 다른 품종/대목이면
동일 품종으로 합치지 않고 새 프로필과 필요한 보정/모델 검토를 기록한다.
농장 모집·동의/자료 수집 준비는 작물 엔진·KMA·전체 Compose 완료를 기다리지 않는다.
공개 해외 자료는 국내 독립 검증으로 계산하지 않는다.

원자료 전송 전에 제공자와 다음 범위를 문서화해야 한다. 코드 저장소·CLI 프롬프트에
개인정보/제한 원문을 넣지 않는다. 이 문서 작성은 농장 접촉이나 접근 동의가 아니다.

| 확인 | 남길 증거 |
| --- | --- |
| 제공/사용 주체 | 가명 농장/계약 ID, 서명자 권한, 자료별 소유자/센서·거래처 권리 |
| 사용 목적/기간 | 개발·보정·독립 검증·사업성 분석을 각각 허용하는지, 보존/파기일 |
| CLI/처리 환경 | 외부 모델에 전달 가능한 필드/요약·전달 금지 정보, 사용 환경 승인 |
| 표시/공유 | 내부 계산·외부 집계/도표·원문 공개·재배포 권리를 각각 구분 |
| 철회/정정 | 접근/새 실행 중단 범위, 이미 만든 비공개 증거의 보관/파기, 새 판본 연결 |

계약 내용과 자료 권리를 deterministic G0 검토에 연결한다. 원문과 해시는 사설
아티팩트에 보관하고 공개 등록부에는 개인·영업정보 없는 식별자/상태만 남긴다.
CLI 연구/검토도 허용 범위의 자료만 사용한다. 검토 제안은 자료 승인 자체가 아니다.

## 검증 목적별 자료 묶음

1. **생장:** 종/품종/대목·작기·정식 상태·줄기/식물 밀도·실제 재배 면적,
   수관/실내 온도·PAR·CO₂와 반복 잎 면적/기관 건물 측정, 관리 사건.
2. **생산:** 개화/착과/숙기·과실 개수, 날짜별 생과/건물·등급/불량·수확 사건과
   표본법. 제거된 기관과 아직 붙어 있는 기관의 측정을 구분한다.
3. **물/양분/기후:** 급액/배액/재순환/구매 용수·배지 저장·성분량과 처방,
   습도/환기/난방·공급열·수관/증산의 비교 가능한 측정.
4. **구매 에너지/사업성:** 설비/운전·효율/COP·실제 전력/연료/CO₂ 계량,
   요금/청구·같은 배치의 H/P/S/재고·계약/검수/정산/비용·수금/지급.

생장/생산 검증을 준비하면서 경제 원장 계약이 없다고 모든 측정을 보류하지 않는다.
각 출력에 필요한 묶음의 확보/누락을 별도로 기록한다. EC/pH만으로 개별 양분 질량을
계산하지 않는다. 난방 용량/공급열을 전력 계량으로, 출하를 판매 인정/수금으로 바꾸지 않는다.

## 보정과 독립 검증의 사전 분리

측정 설계 전에 농장·품종/대목·시설·관리·기간·대상 출력·기준선·제외 규칙을 등록한다.
개발/매개변수 보정 기간과 최종 독립 기간/작기는 겹치지 않아야 한다.
동일 작기의 반복 시점을 무작위로 나누어 독립 작기로 표시하지 않는다.
농장/센서가 같은 경우 공유되는 편향과 적용 범위를 기록한다.

G2의 정답 자료는 확보/봉인해 둘 수 있고 모델 완료 뒤 고정한 버전과 비교한다.
G3a 미래 검증은 모델/특성/수치 기준을 먼저 고정하고 결정 시각의 입력 판본과
`available_at`만으로 실행한다. 이후 실내/기상/수확 관측은 정답으로만 사용한다.
사후 관측을 forcing으로 사용한 전체 작기 재현은 미래 예측 검증이 아니다.

최종 독립 자료를 본 뒤 보정하면 그 자료는 새 개발 자료가 되며 새 미사용 기간이
필요하다. 오차 기준은 센서·표본/면적 분모·측정 빈도·의사결정 손실 확인 후 시험 전에
등록한다. 현재 센서 오차나 농장 기록이 없으므로 임의 생물학적 정확도 기준을 정하지 않는다.

## 최종 비교에 필요한 증거

측정/권리와 비교 대상 모델·초기조건/입력·솔버 버전, 독립 계산/재현 증거,
누락/제외와 잔차를 함께 검토한다. LAI/기관량, 첫 수확/누적·시점별 생과량,
계량 자원의 오차/편향과 단순 기준선 대비 결과를 출력별로 보고한다.
미래 경제에는 당시 계약/시장 판본·정산/원장 대사도 필요하다. 두 후보 대응 자료가
없으면 G3b·최적 추천은 계속 보류이며 단일 작기의 독립 검증으로 대신하지 않는다.
