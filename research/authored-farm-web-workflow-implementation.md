# 작성 농장 웹 작업 연결: 합성 소프트웨어 검증

확인일: 2026-09-30. 이 기록은 이미 등록된 작성 농장 판본을 내부 웹에서 검토 접수, 열 계산 접수, 저장 Run 3D 재생으로 연결한 소프트웨어 후보의 증거다. 농장 수치의 타당성이나 G1 통과 기록이 아니다.

## 구현 범위

- 사용자는 서버가 발급한 `scenario_id`와 `scenario_revision`으로 등록 요약을 조회한다. 서버가 반환한 등록·농장·경제·권리 해시와 입력 작업 ID를 표시한다. 원본 농장 입력이나 권리 선언은 요약 응답에 포함되지 않는다.
- 검토 접수는 등록 해시에 고정된 요청과 메모리의 멱등 키를 사용한다. 실제 작업의 완료나 `hold`는 서버 상태/보류 조회로만 표시한다.
- 계산 접수는 검토 작업의 완료 뒤에만 활성화한다. 서버는 별도의 현재 독립 서명 해제와 권리·입력을 다시 확인한다. 요청이 보류되면 3D 링크는 활성화되지 않는다.
- 완료된 작성 열 작업 ID를 기존 저장 Run 조회 화면으로 전달한다. 사용자가 **저장된 Run 조회**를 누르면 기존 장면·그래프·표가 서버의 120개 저장 시점을 읽는다. 작업 단계 화면 자체는 계산값을 생성하지 않는다.

## 확인 절차와 결과

- `cd web && npm run typecheck`: 통과.
- `cd web && npm run test`: 71개 통과, 7개 파일. 새 API 계약 시험 3개 포함.
- `cd web && npm run build`: 통과. 기존 큰 번들 경고는 남음.
- `cd web && OSSF_TEST_WEB_PORT=5174 npm run test:browser`: Chromium 22개 통과. 새 시험 2개는 합성 HTTP 응답으로 등록 조회 → 검토 → 계산 → 작성 Run 3D 이동과 해제 누락 422/동일 멱등 키 재요청을 확인했다. 5174는 로컬 3D 데모(5173)를 유지하면서 시험한 포트다.
- 실제 Chromium 캡처: [데스크톱](artifacts/authored-workflow-desktop.png), [휴대전화](artifacts/authored-workflow-phone.png). 두 이미지의 ID와 상태는 시험용 합성 응답이다.

## 남은 수용 조건

전체 농장 입력 작성 폼과 저장 후 복구 경로는 아직 없다. 등록은 기존 서비스/API 또는 운영자 절차로 먼저 해야 한다. 위 합성 HTTP 브라우저 시험은 실제 PostgreSQL, 독립 검토자, 실제 Codex CLI 실행을 사용하지 않았다. 별도의 [합성 서비스·브라우저 연결 시험](authored-full-software-path-implementation.md)은 실제 PostgreSQL/SCRAM과 HTTPS에서 등록 조회, 신규 검토·계산 작업의 브라우저 접수와 하네스 작업자 완료, 저장 Run 3D를 확인했다. 그 시험의 CLI와 해제 권한은 합성 fixture다. 두 접수 POST의 180초 브라우저 제한은 관측한 지연에 대한 임시 조치로, 운영 지연 수용은 보류다. 실제 CLI `gpt-6-sol`/`xhigh` 검토·출력 기록과 독립 해제, 재실행·복구, 권리·자료 확인이 갖춰질 때까지 `end-to-end-g1`, `web-shell`, `web-replay` 수용 체크와 G1은 보류한다. 생장·수확·구매 에너지·미래 마진·작물 순위는 이 화면의 출력이 아니다.
