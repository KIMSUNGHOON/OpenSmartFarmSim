## 원인과 변경

사용자는 오래 기다려도 UI에서 개발 진행을 확인할 수 없었다. 기존 안내는 빌드 시점의 정적 문구였고,
현재 원 계산 작업은 이미64/64완료였다. 개발용 별도 DB 검사는 사용자 계산으로 자동 게시되지 않았다.
기존 상태 패널에 최근 검증 완료/다음/대기 단계·갱신 시각·새 모델 배포 여부·남은 집중 작업량을 표시했다.
인증 없이 볼 수 있으며,15초마다 공개 기록을 읽는다. 단계 검증 뒤 게시하는 개발 기록이고 선택한 계산의 진행률은 별도로 조회한다.
30분 이상 새 기록이 없으면 마지막 검증 기록임을 표시하고, 오류/형식 실패에는 마지막 정상 기록을 명시한다.
최초 조회 실패도 표시하며 임의 진행률/실행 중 상태/완료 시각을 생성하지 않는다.
기존 panel/타이포/내비게이션을 재사용한 기능 보완이며 최종 제품 디자인 전체 수용은 아니다.

공개 기록은16KiB 이하 닫힌 형식·정해진 단계/상태·UTC·정수 작업량이다. 토큰/농장 원본/CLI 로그는 포함하지 않는다.
NGINX는 저장소 밖 current 파일을 `no-store`로 제공한다. 게시기는 SHA 판본 보존·원자 교체·동일 bytes 재시도 보존·과거/동시각 충돌 거부를 적용한다.
다음 각 단계 수용 시 source→게시기→실제 HTTP bytes/handoff SHA를 대사한다. 빌드/서버 재시작 없이 새 기록을 표시한다.
재기동 때 새 dist와 정확한 NGINX alias를 함께 보존한다. 내장 JSON은 빌드 당시 fallback이며 오래된 시각을 표시한다.
