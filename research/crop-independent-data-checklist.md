# 독립 농장 자료 체크리스트 v1

상태: **요청/점검 양식만 준비, 모두 미확보**. 기준은
[프로토콜](crop-independent-data-protocol.md)과 [확보 상태](crop-independent-data-status.json)다.
숫자/이름을 채워 넣은 예시 농장을 실제 확보한 것으로 기록하지 않는다.

| 묶음 | 필수 확인 | 현재 |
| --- | --- | --- |
| 동의/권리 | 자료별 제공 권한, 목적/보존, CLI 전달 허용, 내부 이용/표시/공개/재배포/철회 | 미확보 |
| 범위 | 가명 농장/구역, 좌표 비공개 범위, 시설/재배 면적 분모, 종/품종/대목·작기 | 미확보 |
| 초기 상태/관리 | 정식 LAI/기관량, 식물/줄기 밀도, 유인/적엽/적과/적심·수확 사건과 시각 | 미확보 |
| forcing | 수관/실내 온도, 수관 위 PAR·CO₂, 센서 위치/오차/보정·단위/시각 의미 | 미확보 |
| 생장 정답 | 반복 LAI/잎 면적·기관 건물, 표본수/방법·뿌리 포함·면적/식물 환산 | 미확보 |
| 생산 정답 | 개화/착과/숙기·과실 개수, 날짜별 생과/건물·등급/불량, 제거 사건 | 미확보 |
| 물/성분 | 급액/배액/재순환/배지 저장/구매 용수, 처방·성분 질량/검사·계량 오차 | 미확보 |
| 에너지/기후 | 온습도/제어·공급열·구매 전력/연료/CO₂ 계량, 설비/운전 효율·청구 | 미확보 |
| 판매/원가 | 배치 H/P/S/반품/폐기/재고·계약/인도/검수/정산·노동/구매 비용·현금 | 미확보 |
| 독립성 | 개발/보정/최종 검증 기간·작기의 사전 분할, 미래 입력 cutoff/당시 판본 | 미확보 |

실제 파일을 받으면 파일별 원 URL/제품 또는 사설 원장 ID, 관측/공표/이용 가능/수집
시각, vintage/revision·원 단위/시간대·QC·raw hash·권리/검토자를 별도 등록한다.
결측과 미지원 필드는 0으로 채우지 않는다. 데이터 수신·G0 승인·G2/G3a 수용은
각각 다른 상태이며 체크리스트 작성만으로 완료하지 않는다.
