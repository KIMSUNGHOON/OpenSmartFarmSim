# 기상청 ASOS 시간자료: G0 적용 가능성 조사

상태: **자료원 후보 확인, 실제 자료 G0 보류** (2026-09-27). 이 문서는 공식 명세와 이용조건을 대조한 결과이며, 인증키 호출·관측소 선택·실측 보유율 검사·제공자 질의는 수행하지 않았다. 출처 조사와 판단은 Codex CLI `gpt-6-sol`, `model_reasoning_effort="xhigh"` 세션 `01a0e294-1d9d-70b2-bfbb-96a0a58eb112`에서 검토했고 공식 가이드·출처 충돌은 아래 기록의 별도 세션에서 감사했다. 실제 채택은 서버의 출처·권리·품질 검사와 검토자 승인이 필요하다.

## 일사량, 적산 구간, 시각

API허브는 시간자료 `SI`를 MJ/m²로 표기한다. 기상청 [지상기상관측지침 §2.4.8](https://data.kma.go.kr/resources/images/publication/%EC%A7%80%EC%83%81%EA%B8%B0%EC%83%81%EA%B4%80%EC%B8%A1%EC%A7%80%EC%B9%A8.pdf)은 1시간 일사량을 매분 수신한 일누적 일사량에서 산출한다고 설명한다. 따라서 `SI`는 **한 시간에 모인 단위면적당 에너지**로 해석할 근거가 있다. 순간 일사강도 W/m²처럼 직접 넣을 수 없다. 공공데이터포털 제품의 공식 가이드도 `icsr` 단위를 MJ/m²로 적지만, `SI`와 `icsr`가 같은 원본 판본·결측 규칙·값인지까지 증명하지 않는다. [API허브 ASOS 명세](https://apihub.kma.go.kr/apiList.do?seqApi=2), [공공데이터포털 공식 가이드](https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000002411530&fileDetailSn=1).

**보류:** API허브 `TM`은 KST 관측시각이라고만 명시한다. `SI`의 1시간 구간이 `TM` 직전인지, 시작·끝 분을 포함하는지, `00:00` 행이 어느 날짜의 에너지를 뜻하는지는 명세·지침에서 확정되지 않았다. 지침의 일 일사량 `00:00–24:00` 집계만으로 시간자료의 경계를 역산하지 않는다. `TM=00:00 KST`라는 **라벨 자체**는 전날 `15:00 UTC`로 변환되지만, 제공자의 구간 정의가 없으면 해당 에너지의 UTC 시작/끝을 부여하지 않는다. 공공데이터포털의 `tm` 시간대도 제품 페이지·가이드에서 명시적으로 확인되지 않았다. `(TM−1시간, TM]`과 `icsr=SI`는 공급자 확인 전 가설이다. [API허브 ASOS 명세](https://apihub.kma.go.kr/apiList.do?seqApi=2), [공공데이터포털 제품](https://www.data.go.kr/data/15057210/openapi.do), [지상기상관측지침](https://data.kma.go.kr/resources/images/publication/%EC%A7%80%EC%83%81%EA%B8%B0%EC%83%81%EA%B4%80%EC%B8%A1%EC%A7%80%EC%B9%A8.pdf).

## 가용성·품질·과거 판본

- 포털 ASOS 화면이 열거한 제공자 QC 플래그 대상은 기온·습도·기압·지면온도·풍향·풍속·**일조**이며 **일사**는 없다. 공공데이터포털 시간 API의 출력 표에도 `icsr`의 QC 필드는 없고, API허브 시간자료 표에도 `SI` QC 필드는 없다. 반면 기상청의 [기상기후데이터위키](https://datawiki.kma.go.kr/doku.php?id=%EA%B8%B0%EC%83%81%EA%B4%80%EC%B8%A1:%EC%A7%80%EC%83%81:%EC%9E%90%EB%8F%99%EA%B8%B0%EC%83%81%EA%B4%80%EC%B8%A1_aws)는 **개방포털 시간자료 변수 목록**에 `일사 QC플래그`를 열거한다. 공식 설명끼리 맞지 않으므로 `SI`/`icsr`에 제공자 QC가 없다고도, 정상이라고도 판정하지 않는다. 실제 연결 제품의 응답 필드와 제공자의 설명을 확인해야 한다. 품질지침은 자동/수동 품질검사와 수동 결과 변경을 설명한다. 결측, 센서 오류, 이상 일사값, 정정 여부는 별도 검사한다. [포털 ASOS 설명](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36&tabNo=2), [공공데이터포털 시간 API](https://www.data.go.kr/data/15057210/openapi.do), [API허브 ASOS 명세](https://apihub.kma.go.kr/apiList.do?seqApi=2), [지상기상관측지침](https://data.kma.go.kr/resources/images/publication/%EC%A7%80%EC%83%81%EA%B8%B0%EC%83%81%EA%B4%80%EC%B8%A1%EC%A7%80%EC%B9%A8.pdf).
- 공공데이터포털 페이지의 D−1·첨부 가이드의 11시·개방포털 화면의 10시는 **경로별 제공 안내**다. API허브 기간 조회의 개별 값 `available_at` 보장은 찾지 못했다. 어느 안내도 정정 전 원본과 당시 공표시각을 복원해 주지 않는다. [제품 `15057210`](https://www.data.go.kr/data/15057210/openapi.do), [공식 가이드](https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000002411530&fileDetailSn=1), [포털 ASOS 설명](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36&tabNo=2).
- 이 문서에서 확인한 API 응답 필드에 원본별 `published_at`/`revision_id`는 없다. [지침의 수동 품질검사](https://data.kma.go.kr/resources/images/publication/%EC%A7%80%EC%83%81%EA%B8%B0%EC%83%81%EA%B4%80%EC%B8%A1%EC%A7%80%EC%B9%A8.pdf)는 판단 변경 가능성을 보여 주지만 모든 값이 바뀌었다는 뜻은 아니다. 실제 수집 시각·HTTP 응답·요청 조건·원본 SHA-256을 버전으로 고정하고 재조회 차이를 새 판본으로 남겨야 한다. 이전 시점에 보였던 값이 보관되지 않았다면 그 시점의 결정 입력이었다고 주장하지 않는다. 이는 프로젝트의 보수적 **as-of 설계 판단**이다.

## 권리: 제품 표시와 실제 사용 행위를 분리

[공공데이터포털 `15057210`](https://www.data.go.kr/data/15057210/openapi.do)은 무료·**공공누리 제1유형 출처표시**·개발/운영 자동승인으로 표시된다. [공공누리 제1유형 일반증서](https://www.kogl.or.kr/info/licenseType1.do)는 그 유형이 적용된 저작물의 공유, 2차 변형, 영리 이용을 출처표시 조건으로 허용한다. 온라인에서는 가능한 경우 출처 링크를 제공하고 기관의 후원을 암시하지 않아야 한다. 이는 해당 제품을 검토할 **유력한 이용 허락 근거**지만, 특정 원본의 제3자 권리·접근 계정·표시 방식·재배포 범위를 검토 없이 자동 승인하는 근거로 사용하지 않는다. [기상청 개방포털 저작권 정책](https://data.kma.go.kr/cmmn/static/staticPage.do?page=pageCr)은 자료별 공공누리 표시를 확인하고 미표시 자료는 담당자와 협의하라고 한다.

## G0를 향한 가장 작은 다음 확인

1. **제공자 서면 질의:** 두 경로의 `SI`/`icsr` 동일성, 한 시간 적산의 시작·끝/포함 분, `00:00`의 귀속일, 공공데이터포털 `tm`의 시간대, 요청기간 양끝 포함 여부를 확인한다. 개방포털 설명과 데이터위키의 일사 QC 표기가 왜 다른지, 연결 제품에서 일사 QC 필드·코드가 있는지와 결측·센서 이상 처리도 묻는다. 최초 게시와 정정 시각·이전 판본 조회 가능 여부도 묻는다.
2. **권리/계정 질의:** 사용할 경로와 제품 ID를 특정해 API 접근, 원본 장기 저장, 변환, 출처를 붙인 계산값 화면 표시, 상업 서비스, 원본 재배포/예제 동봉을 각각 확인한다. 제3자 권리와 공공누리 적용 대상·표시 문구, 운영 승인·할당량도 기록한다.
3. **권한을 얻은 뒤 한정 조회:** 아직 지점을 선택하지 않는다. 승인된 후보 지점/짧은 기간에서 정오와 자정 경계, 페이지 경계, 결측을 포함하는 원본을 비공개 저장소에 해시로 고정한다. `pageNo`/`numOfRows`를 명시하고 `totalCount`·중복/누락을 검사한다. API허브를 시험하면 31일 이내 요청으로 분할해 경계 중복/누락을 검사한다. 제공자가 구간을 확인한 후에만 두 경로와 일합, UTC 변환을 대조한다. 지점·요소별 보유율과 현장 좌표의 대표성은 별도 기록한다.
4. **판본 채택:** 출처 URL/제품 ID, 지점·요소·관측기간, 원본 요청·응답 해시, 관측/게시/수집/이용 가능 시각, 단위·변환 버전, 제공자 QC와 프로젝트 QC, 권리·검토자를 묶는다. 소급 수집한 최신값은 당시 판본으로 위장하지 않고 `ex_post_replay`로 구분한다. CLI 제안은 서버 G0 검사에 입력될 증거일 뿐 승인 자체가 아니다.

**결론:** 공식 명세는 수집 어댑터의 후보 계약을 세우기에 충분하다. 특정 지점의 `SI` 완전성·정확한 적산 구간/시각 경계·제품별 권리/계정·시점 판본이 아직 확인되지 않았으므로 실제 KMA 입력의 **G0는 HOLD**다.
