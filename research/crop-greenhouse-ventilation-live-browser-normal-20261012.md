  WebGL 전달값과 표·25장부·10수지·환기 진단이 일치했다. 실제 draw call은 양수다.

## 진단과 수정

두 사용자 서버를 함께 유지한 최초 빌드는 합 RSS 제한으로 제외했다. 별도 자원 창의 v2가 통과했다.
정상 v1은 시험 인증서의 DNS SAN이 제품 NGINX의 `localhost` 검증과 맞지 않았고,
server 생성 전 FD 기준선도 잘못 잡았다. 시험 인증서/측정 순서를 고쳤으며 TLS 검증은 유지했다.
v2는 실제 화면 검증 뒤 최종 직접 조회가 HTTP principal 없이 실행되어 실패했다.
최종 확인을 실제 인증 HTTPS로 바꾼 v3 전체 실행만 수용했다.

제품 소스의 수정은 누적 장부 접근성 이름의 22→25 정정이다.
계산식·작업자·API·기존 장면/차트·기하 코드는 변경하지 않았다.
첫 보존 guard의 child 0 영수증은 남았지만 compaction 뒤 원 도구 반환을 복구하지 못했다.
같은 보존 단언을 별도 불변 영수증으로 다시 실행하고 원 도구 31062의 실제 종료 0을 수집했다.
