  수치 작업자는 별도 프로세스로 유지했다. 전체 OpenAPI 생성 대신 인증된 실제 작업 조회의404로 기동을 확인한다.

  Chromium/CDP를 직접 사용하고 실제 `fetch`의 `Response.clone()`으로 본문을 수집한다.
  추가 API 요청을 만들지 않으며 중단된 GET·관측된503은 별도로 기록한다. 화면 수치는 완료된 원 응답과 대사한다.

  문맥별 계측을 집중2검사(원97687 실제0)로 확인했다. API 조회11건은 계산/쓰기0이다.
