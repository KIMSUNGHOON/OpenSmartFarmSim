# 자료·연구 기준선

상태: **2026-09-27에 확인한 1차 출처와 설계 판단.** 링크는 제공기관 또는 원 연구의 페이지로 직접 연결한다. 페이지에 적힌 사실과 이 프로젝트의 추론을 구분한다. 실제 좌표의 보유율·오차·권리는 아직 확인하지 않았으므로 이 표만으로 자동 수집이나 추천을 출시하지 않는다. 제품 범위는 [명세](PROJECT_SPEC.md), 실행 구조는 [아키텍처](ARCHITECTURE.md)를 따른다. **가격·요금·비용·등급별 판매·권리의 상세 원천→필드 계약과 손익 검증은 [경제 계약](ECONOMICS.md)을 따른다.**

## 자료 항목과 출처

| 자료 유형·필드 / 용도 | 1차 출처와 공간·시간 의미 | 권리·누락 시 처리 |
| --- | --- | --- |
| **위치**: WGS84 경도·위도, 선택 좌표, 주소/지역명, 고도 / 관측소와 격자 연결 | 사용자가 직접 지정한 좌표가 기준이다. [기상청 단기예보 API](https://apihub.kma.go.kr/apiList.do?seqApi=10)에는 위경도↔예보 격자 변환이 있다. 주소 좌표는 편의 기능 후보이며 농지의 실제 좌표를 대신하지 않는다. | 사용자가 입력한 좌표의 저장·공유 범위를 고지한다. 고도 출처와 주소 변환 API의 재사용 권리는 **미확인**. 실제 부지 좌표가 없으면 대표 위치의 *탐색 실행*으로 표시한다. |
| **과거 외기**: 관측시각, 기온 °C, 상대습도 %, 풍속 m/s, 강수량 mm, 일사 MJ/m², 항목별 제공자 QC 유무와 프로젝트 검사 / 열·수증기 모델 | [기상청 ASOS 시간자료 API](https://apihub.kma.go.kr/apiList.do)는 관측소별 시간자료와 일사 `SI`를 설명하지만 이 API의 출력 필드 목록에는 일사 QC 플래그가 없다. [기상자료개방포털의 ASOS 설명](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36&tabNo=2)은 별도 서비스의 시간/분 QC 제공 요소를 기온·습도·기압·지면온도·풍향·풍속·**일조**로 한정하며 **일사**를 열거하지 않는다. 관측소는 지점이며 필지 관측이나 5 km 격자 값이 아니다. 지점별 요소·기간·결측은 실제 조회로 확인한다. | [기상청 저작권 정책](https://data.kma.go.kr/cmmn/static/staticPage.do?page=pageCr)에 따라 항목의 공공누리 표시 및 출처표시·재배포 조건을 확인한다. 제공자 QC가 없는 일사를 정상으로 간주하지 않고 별도 품질 검사를 요구한다. 일사 등 핵심 항목이 없거나 검사에 실패하면 현장용 실행을 차단한다. 강수 결측은 0으로 바꾸지 않는다. |
| **과거 보조 일사·기상**: 격자/제품 버전, UTC 시간값 / 민감도 비교 | [NASA POWER 시간 API](https://power.larc.nasa.gov/docs/services/api/temporal/hourly/)는 2001년부터의 시간자료와 UTC 요청 방식을 설명한다. [제공기관 안내](https://power.larc.nasa.gov/docs/tutorials/service-data-request/api/)의 기상 해상도는 0.5°×0.625°, 일사는 1°×1°다. 현장과 큰 공간 차이가 날 수 있다. | [POWER 인용 지침](https://power.larc.nasa.gov/docs/referencing/)의 제품·버전·접근일 표기 및 재배포 통지 요청을 따른다. 전체 산출물의 단일 재배포 허가는 **미확인**. 검증 전에는 명시적 *저해상도 탐색 대안*으로만 사용하고 현장 추천의 빈칸을 조용히 메우지 않는다. |
| **전망 외기**: 발표시각, 유효시각, TMP/REH/WSD/PCP / 별도 전망 모드 | [기상청 단기예보](https://apihub.kma.go.kr/apiList.do?seqApi=10)는 5 km 격자와 3시간마다 발표, 변수 목록을 명시한다. 현재 목록에 일사는 없다. 과거 관측과 섞어 하나의 ‘실측’ 시계열을 만들지 않는다. | 동일한 기상청 권리 확인과 발표분별 보존이 필요하다. 일사가 필요한 온실 계산은 전망 모드의 일사 자료원이 확정될 때까지 **미지원**이다. |
| **전망 일사 후보**: ssrd, 예보 주기·적산 구간 / 향후 모드 | [ECMWF 공개 예보](https://www.ecmwf.int/en/forecasts/datasets/open-data)는 ssrd와 0.25° GRIB2 공개 제품, 최근 발표분만 유지하는 방식을 설명한다. 적산량의 구간·단위 변환이 필요하다. 국내 5 km 기상청 예보와 합친 현장 오차는 **미확인**. | 공개 제품은 [ECMWF 조건](https://www.ecmwf.int/en/forecasts/datasets/open-data)상 CC BY 4.0과 출처표시를 요구한다. 예보 원본·발표시각을 저장하지 못하면 재현 가능한 전망 실행을 내지 않는다. |
| **온실·관리**: 면적 m², 체적 m³, 피복 투과율/열손실, 난방 **공급열 용량인지 명시한** kW_th, 환기 용량, 설정값, 가동·공급열(kWh_th)/구매 전력(kWh_e)/연료(L·kg·kWh_fuel) 계량, 초기 실내 온습도, 식재밀도 / 경계조건과 보정 | 사용자·협력 농장의 시설 명세와 센서/계량 로그가 우선이다. [WUR 온실 물리 모델](https://research.wur.nl/en/publications/a-validated-physical-model-of-greenhouse-climate/)도 기상 외에 온실·작물·제어 특성을 입력으로 둔다. [미국 에너지부](https://www.energy.gov/cmei/femp/purchasing-energy-efficient-geothermal-heat-pumps)는 히트펌프 COP를 공급열과 전기 입력의 비율로 정의한다. 따라서 난방 용량 kW만으로 실제 소비 전력·연료를 알 수 없다는 것은 **프로젝트 추론**이다. | 시설·로그 자료는 제공자의 계약/동의를 기록한다. 용량의 물리적 의미, 운전점별 효율/COP, 보조 설비 전력, 연료 발열량과 기준(HHV/LHV)을 확인한다. 없으면 공급열 또는 열수요만 모델값으로 표시하고 구매 전력·연료·비용 계산은 보류한다. 결측 설비 용량을 ‘평균 온실’로 감추지 않는다. |
| **작물 프로필**: 종·품종, 작기/단계, 온습도·광·CO₂·급액 범위와 근거, 식재밀도 / 조건 평가 | [농사로 작목별 매뉴얼](https://nongsaro.go.kr/portal/ps/psx/psxj/cropManualMain.mo?farmerMainFlag=VC011205) 등 원문과 현장 관찰을 Codex가 대조해 버전별 규칙으로 등록한다. 개별 품종·작기 수치는 아직 **미확인**. | [농사로 저작권 정책](https://www.nongsaro.go.kr/portal/ps/psz/psza/contentMain.mo?menuId=PS00190)은 공공누리 유형별 제한과 미표시 자료의 사전 협의를 명시한다. 권리 미확인 원문을 자동 복제·재배포하지 않고 프로필 등록을 보류한다. |
| **급액·배액·배지**: 유량 L, 배지 수분/질량, EC·pH, 재순환/배출 / 후속 물수지 | 협력 농장 계량을 사용한다. [WUR 토마토 온실 데이터](https://research.wur.nl/en/datasets/autonomous-greenhouse-challenge-second-edition-2019/)는 급액·배액·기후·설비·수확 등 실제 측정 항목의 사례다. | 데이터셋의 개별 파일 라이선스와 농장 로그 공유권은 **미확인**. 초기에 물 사용을 계산 상태로 주장하지 않으며, 한도가 있으면 입력 제약으로만 저장한다. |
| **수확·경제·비교 검증**: 수확·판매 가능·판매 인정·반품·폐기·재고 kg, 품질, 가격/시점/시장, 종자·배지·물·구매 전력·연료·노동·시설비와 후보별 같은 기준의 결과 / 후속 순위 | 협력 농장의 작기별 원장·등급별 packout·출하 정산·구매 에너지 청구서와 가격 근거가 필요하다. [aT KAMIS 가격통계](https://www.kamis.or.kr/customer/price/statistics.do)의 도매가격은 중도매인 판매가격이며 농가 실수취가가 아니다. [농촌진흥청 농산물소득조사](https://nongsaro.go.kr/portal/ps/psz/psza/contentMain.ps?menuId=PS65442)는 비용 항목 참고이며 해당 농장 실적이 아니다. 이 **조사 개요 페이지는 공공누리 제2유형(상업적 이용 금지)**으로 표시되어 있어, 상업 서비스의 원문 재사용은 개별 권한을 확인해야 한다. [WUR 토마토 데이터](https://research.wur.nl/en/datasets/autonomous-greenhouse-challenge-second-edition-2019/)는 변수 설계 참고이며 국내 가격·수익 또는 **작물 간 선택** 데이터가 아니다. **프로젝트 검증 설계:** 같은 지역·시설형·기간·면적·관리/비용 기준·목표에서 둘 이상 후보를 시험구나 대응 작기로 비교하고, 모델 개발·보정·후보 선택에 쓰지 않은 결과로 순위와 후회 손실을 평가한다. | 대응 작물 자료와 공유권은 **외부 협력 의존성**이다. 사업 기밀·개인정보 및 제공권을 따로 관리한다. 후보별 자료만 있거나 비교 조건이 맞지 않으면 G3 순위 검증으로 인정하지 않는다. 첫 내부 시범의 **가정 기반 손익 계산**은 명시할 수 있지만 미래 순이익 예측·‘경제적 최적’은 표시하지 않는다. |
| **노지 토양·토지피복**: 토성·pH·배수·토지피복 / 후속 노지 제품 | [흙토람 토양도](https://soil.rda.go.kr/community/application.do)는 신청 대상과 비영리 공익 목적 제한을 밝힌다. [ISRIC SoilGrids](https://isric.org/explore/soilgrids)는 250 m 예측 지도이고 [이용 정책](https://docs.isric.org/globaldata/soilgrids/SoilGrids_faqs_02.html)은 CC BY 4.0이다. [ESA WorldCover](https://esa-worldcover.org/en/data-access)는 2020/2021 토지피복이다. | 온실 배지에 자연 토양 적성도를 적용하지 않는다. 흙토람 공개 열람을 대량 수집 권한으로 해석하지 않는다. SoilGrids/WorldCover도 현재 필지의 토양검정·농지 적법성 증거가 아니다. 첫 제품의 계산 입력에서 제외한다. |

## 작물 선택의 시장·거시 기준선

아래는 **입력 후보**이며 채택·예측·게시 조건의 전체 설계는 [시장·거시 환경 명세](MARKET_INTELLIGENCE.md)를 따른다. 정식/파종 결정시각 `D`에 이미 발표·접근 가능했던 **원본 버전**만 당시 입력으로 쓴다. 관측 대상 시각, 전망 발행 시각, 수집 시각과 사후 정정본을 구분한다. KREI 단기 전망의 기간과 후보 작물의 실제 수확·판매 기간이 다르면 그 전망을 수확기 가격으로 연장하지 않는다. **공개 가격 계열 어느 것도 농가 순실수취 단가가 아니다.**

## 수집·품질 판단

1. 좌표가 한국 육지와 지원 가능한 관측 범위인지 검사한다. 관측소는 거리만이 아니라 고도 차, 운영기간, 필요한 요소의 품질·결측률을 보고 선택한다. 관측소 선택과 오차의 허용치는 시범 좌표의 실제 자료로 정한다.
2. 원본 응답과 요청 조건, 수집시각, 제공자·제품/지점 ID, 관측시각 또는 예보 발표·유효시각, 원 단위, **변수별 제공자 QC 값 또는 미제공 상태**, 프로젝트 검사 결과, 권리 상태와 SHA-256을 연결한다. 제공자 QC와 프로젝트 검사를 하나의 ‘정상’ 표시로 합치지 않는다. 원본을 덮어쓰지 않고 정규화본을 새 버전으로 만든다. 이것은 [W3C PROV 출처 추적 개념](https://www.w3.org/TR/prov-o/)을 따른 **프로젝트 설계**다.
3. 모든 계산 시각은 UTC로 저장하고 KST 표시를 별도로 만든다. 온도·습도처럼 순간/평균값과 일사·강수처럼 구간 적산값을 구분해 변환한다. [POWER 기본 시간은 현지 태양시](https://power.larc.nasa.gov/docs/services/api/temporal/hourly/)이므로 사용할 경우 명시적으로 UTC를 요청한다.
4. 결측·이상값·단위 오류는 자료 보고서에 남긴다. **일사는 제공자 QC를 기대하지 않고** 지점/기간별 보유율, 음수·비정상 야간값, 태양 위치와 맞지 않는 물리 범위, 시간 간격/적산 일치, 인접 지점이나 독립 계측과의 차이를 프로젝트 검사로 평가한다. 허용치는 지점·계절·센서 특성을 확인해 사전에 정하고, 검사 버전·결과·제외 사유를 남긴다. 일조 QC를 일사 QC로 바꿔 쓰지 않는다. 온도/습도의 짧은 공백 보간도 길이와 방법을 기록하고, 일사/강수 누적량은 보존 규칙 없이 보간하지 않는다. 핵심 입력 공백은 실행 실패 또는 탐색용 격하로 처리한다. 다른 자료원으로 대체하면 결과에서 두 출처를 구별하고 불확실성을 다시 계산한다.
5. 수집 실패·요청 한도는 캐시·백오프·재시도로 다루며 원본이 확정되지 않은 실행은 시작하지 않는다. 공급자가 나중에 값을 고쳐도 이전 실행은 원래 스냅샷을 참조한다.

## 모델 선택의 근거와 충돌 해결

이전 연구 메모는 ‘온도만 계산하는 교육용 시연’, ‘열·수증기·CO₂와 관수·수확까지 계산’, ‘한 작물 조건부 평가’를 각각 제안했다. 이번 제품 목표에는 지역→자료→계산→3D→추천의 **완주 흐름**이 필요하지만, [WUR 온실 물리 모델](https://research.wur.nl/en/publications/a-validated-physical-model-of-greenhouse-climate/)과 [GreenLight 평가](https://research.wur.nl/en/publications/greenlight-an-open-source-model-for-greenhouses-with-supplemental/)가 보여주는 모델 요구와 검증 범위를 국내 농장에 곧바로 일반화할 수 없다. 따라서 **첫 모델은 단일 구역 열·수증기 수지**로 정했다. 다음 생육 계산은 위 2026-10-04 계약으로 개발하며, CO₂·배지 물·수확의 실제 적용/예측 주장은 해당 자료와 검증이 확보된 범위에서 연다. 온도만으로 종합 작물 적합도를 주장하지 않는다.

[Vanthoor 토마토 수확 모델](https://research.wur.nl/en/publications/a-methodology-for-model-based-greenhouse-design-part-2-descriptio/)은 유럽 조건에서 검증된 연구이며 국내 품종의 정확도를 증명하지 않는다. [FAO AquaCrop](https://www.fao.org/aquacrop/overview/input-requirements/)은 기상·작물·토양·관리 자료가 필요한 토양 중심 모델이다. 배지재배 첫 수확 엔진으로 선택하지 않는다. 이 선택은 연구를 무시한다는 뜻이 아니라 적용 범위를 지킨다는 뜻이다.
