Ubuntu's [fonts-noto-cjk package](https://archive.ubuntu.com/ubuntu/pool/main/f/fonts-noto-cjk/fonts-noto-cjk_20230817+repack1-3_all.deb),
version `1:20230817+repack1-3`, was downloaded and checked against the local

`7d64b985f6fe128c99eae5610d5c047338e572bdcfb2bb09736be01b824a7f6c`.
It was extracted into an owned temporary directory. A path-only wrapper defines
`NotoCJKFontPath` before loading the original LaTeX; neither source nor system
fonts were modified. The existing [font rights record](README.md#출처와-이용-범위)
continues to apply.

Tectonic used an isolated temporary cache and output directory, with
`--keep-logs`, at `nice -n 10`. Two complete GNU builds succeeded. Its internal
reruns resolve the table of contents and references. Temporary rendering tools
were `pypdfium2 5.13.0` and `Pillow 12.3.0`; they are not product dependencies.
Rendering was sequential and its document/page/bitmap resources were closed.
The [PDFium wrapper documentation](https://pypdfium2.readthedocs.io/en/stable/python_api.html)
describes this resource lifecycle and prohibits simultaneous PDFium calls from
multiple threads.
