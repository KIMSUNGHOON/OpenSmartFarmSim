# 첫 사용자 화면 설계 기준

상태: **시안 선택·검토 완료, 구현 전**. 네 가지 생성 시안 중 밝은 계측기형 대시보드 D의 정보 구조를 택하고, A의 큰 글자와 단계별 안내를 결합한다. 이는 정확한 Codex CLI `gpt-6-sol`/`xhigh` 독립 화면 검토(`01a0e272-3c7d-7af1-86ce-a9645621c622`)의 판단이다. D 시안 원본 SHA-256은 `47f02387a0abaab8ef5530089df199888ce3cb55a863644a2893350cd08e1d7b`다. 시안의 숫자·배지·차트·문구는 **디자인 예시**이며 제품 결과나 자료 권리의 증거가 아니다.

## 화면 흐름

1. **입력:** 국내 좌표 한 점, 가상 적용 시각을 가진 두 시간, 온실 한 구역과 명시적 사용자 가정을 받는다. 입력마다 단위·뜻·출처를 평이한 한국어로 설명하고, 합성 자료 계약 시험임을 첫 화면에서 밝힌다.
2. **작업:** 실제 Codex CLI의 조사·수집 검토·평가 세 단계를 서버 작업 상태와 연결한다. 단계별 시도·보류 이유와 다시 확인할 수 있는 근거만 보여 준다. 단순히 모델 문자열이 저장됐다는 이유로 실행 완료를 표시하지 않는다.
3. **재생:** 서버가 승인한 Run의 `run_id + timestamp`를 단일 선택 상태로 두고 3D 장면, 온도·습도·제어·모델 열수요/공급열 그래프, HTML 표·문장이 같은 값을 읽는다. 서버 승인 전 계산은 `candidate`로 구별한다. 구매 에너지, 실측 센서, 생장·수확 애니메이션은 만들지 않는다.
4. **경제·평가:** 시장 문맥이 `unavailable`이면 보류 보고서를 보여 준다. 수요·공급·거시 충격 및 금액은 `사용자 가정에 따른 조건부 계산`으로 표시하고 미확인 비용을 0으로 치환하지 않는다. 최종 카드는 `작물 선택 판단 보류`와 필요한 실제 자료·현장 측정·미래 검증·대응 작물 비교를 설명한다.

## 시안에서 제거할 잘못된 표현

생성 화면의 연간 그래프, 24시간 재생, 기상청·실제 관측·센서 이력 배지, QC 완료 표시, 예측 범위·전기 요금·미래 이익·작물 순위는 현 구현의 근거 범위를 넘는다. 화면 구현에서 해당 텍스트와 예시 숫자를 가져오지 않는다. 가상 적용 시각은 관측 시각으로 표시하지 않고, 합성 자체 검토를 외부 원천 G0 승인으로 표시하지 않는다. 첫 G1이 완료돼도 G2·G3a·G3b·G4의 주장 관문은 별도로 남는다.

## 접근성·반응형 수용

- 상태를 색만으로 구별하지 않고 `합성`, `후보`, `보류`를 글자로 적는다. 탐색·입력·시각 선택·재생 제어는 키보드로 작동하고 초점이 보인다.
- 시각 선택 컨트롤은 UTC와 KST 표기·단위를 명시한다. 사용자가 고른 시각의 값은 장면이 없어도 표와 문장으로 읽을 수 있고, 동작 줄이기 설정을 존중한다.
- 좁은 화면에서는 입력 → 작업 → 재생 → 근거 → 경제 → 평가 순서로 쌓는다. 글자 200% 확대와 WebGL 부재에서 내용·표·조작을 잃지 않는다.
- 원본 시안의 장식용 대형 조절 다이얼과 작은 저대비 배지는 제거한다. 실제 앱의 입력·상태를 우선하는 명확한 제목과 충분한 글자 크기를 쓴다.

생성 화면과 변환 HTML은 그대로 제품에 게시하지 않는다. 화면 구현은 이 문서와 [첫 구현 범위](IMPLEMENTATION_SLICE.md), [관문](PROJECT_SPEC.md)을 기준으로 실제 API 데이터에 결합하고, 외부 자산·폰트의 이용 조건을 확인한 뒤 브라우저에서 원본 시안과 가독성·반응형을 비교한다. [12ui 이용약관](https://12ui.com/terms)은 생성 출력과 참고 코퍼스 이미지를 구분하므로 코퍼스 참고 이미지는 저장소에 넣지 않는다.

시안 확장 run `crt-1182dd69060ff6b898bcb92a13d80e71eb3c788c`는 네 후속 화면 이미지를 만들었지만 시작 화면 HTML 변환이 `LayerDoc source is invalid`로 실패했다. 별도 프로토타입은 생성됐으나 목적지 13개 중 9개가 임시 화면이고 선택기 5개가 정적 상태다. 이를 사용자 경로 구현·시험 성공으로 취급하지 않는다.
