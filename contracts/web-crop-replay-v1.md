# 계산 기반 작물 연구 재생 — v1

상태: 로컬 합성 연구 소프트웨어 수용, 2026-10-04. 선행은
[저장 조회 API](api-crop-replay-v1.md)이며 [수용 기록](../research/web-crop-replay-implementation.md)에
실제 저장/HTTPS/장면 대사와 범위·보류를 남긴다. 이 계약은 승인 Run 또는 G0–G4 판정을 만들지 않는다.

## 입력과 현재 연결

- 기존 메모리 Bearer 클라이언트로 `GET /v1/crop-research-results/{result_id}`를 읽는다.
  result ID와 `scenario_id / scenario_revision / registration_sha256 / crop_id`를
  응답에 대사한다. ID와 현재 연결을 바꾸면 이전 결과·장면·그래프·재생을 즉시 지운다.
  늦게 도착한 이전 응답은 버린다. 새로고침 뒤 인증/결과는 다시 조회한다.
- 응답의 닫힌 키, 버전, 연구 범위, UTC, 유한 수치, 단위, 배열 한도,
  시작/끝·시점 순서와 완료/hold 구분을 검사한다. 원문이나 브라우저 계산으로
  서버의 현재 권리·HMAC 검증을 대신하지 않는다. 금액·성장 수식을 실행하지 않는다.
- 기존 30초 제한과 no-store/credentials omit/redirect error를 유지한다.
  최대 응답 읽기는 서버 패킷 한도인 64 MiB 이내로 제한한다.

## 같은 시점의 세 표현

1. 하나의 저장 `result_id + farm + manifest + sample.at`가 수치, 표, 그래프와
   3D의 원천이다. 선택은 저장 sample의 정수 인덱스이며 중간 상태를 계산하지 않는다.
2. 잎·줄기/뿌리·과실·버퍼는 **mg_CH2O/m2_floor**다. 줄기와 뿌리를 따로 나누지
   않으며 탄소를 생과 kg·개수·수확·판매량으로 바꾸지 않는다.
3. LAI는 **m2_leaf/m2_floor**다. 3D의 논리적 바닥을 1 m²로 정규화하고, 고정된
   설명용 잎 면들의 **한 면 삼각형 면적 합계**를 선택한 LAI × 1 m²와 대사한다.
   양면 렌더링은 면적을 두 배로 세지 않는다. 실제 삼각형 좌표/변환에서 면적을
   측정한다. Float32 도형 오차 허용은 `max(1e-8, LAI × 1e-6)`다.
4. 잎 면의 배치·방향·패치 수·지지선은 모식 배치다. 식물 키·잎수·착과수·숙기·
   실제 도면은 계산 출력이 아니다. 영 LAI는 잎 면을 숨기고 숫자 0을 유지한다.
   기관 탄소 비교 막대는 같은 결과 전체에서 고정한 공통 척도를 쓰며 길이·열매
   크기로 해석하지 않는다. 거대한 수치/장치 오류로 도형을 안전하게 만들 수 없으면
   표·텍스트를 유지하고 3D 사용 불가를 표시한다.
5. 그래프는 한 단위의 저장 값만 연결한다. 직선 연결은 중간 시점 계산이 아님을
   표시한다. 자동 재생도 저장 시점만 이동하며 문서 숨김·끝·사용자 조작 때 멈춘다.
   움직임 줄이기 설정에서는 자동 재생을 비활성화한다.
6. 합성 계산·품종 미검증·미게시 연구·관문 미평가와 시계열 길이를 명확히 표시한다.
   5분 fixture를 전체 작기로 제시하지 않는다. 제거 사건은 입력된 탄소 제거이며
   적정 관리·생과 수확으로 표시하지 않는다.

## hold, 장애와 접근성

수치 hold에서는 정상 성장 장면/그래프/완료 sample 표를 만들지 않는다. 서버의
reason code·해당 solver 시각/phase·마지막 확인 상태/실패 진단만 별도로 표시한다.
조회 권리 거부·잘못된 응답·네트워크 실패는 이전 값 없이 이유와 다시 조회를 제공한다.
서버 권리의 실시간 푸시를 주장하지 않으며, 사용자가 다시 조회하면 현재 권리를 검사한다.

키보드 이전/다음·range·HTML 표의 시점 선택·카메라 버튼을 제공한다. WebGL2 미지원,
context loss/restoration에서도 표·그래프·같은 시점 설명을 유지한다. 장면은 값/카메라/
크기 변경 때만 그리며 계속 도는 렌더 루프는 만들지 않는다. GPU·관찰자·이벤트·타이머는
해제한다. 좁은 화면/확대에서도 본문 밖 가로 넘침 없이 표 영역 안에서 스크롤한다.

## 수용 증거

- 닫힌 decoder의 숫자/단위/범위·ID/농장 혼합·UTC·hold 반례, 실제 도형 면적 대사.
- typecheck/build와 집중 Chromium: 저장 시점·그래프/표/3D 숫자, 키보드,
  모바일/확대·움직임 줄이기·WebGL 불가/loss/restore, 현재 조회 거부·계정 변경/늦은 응답.
- 실제 SCRAM 저장 → 표준 HTTPS → 브라우저에서 같은 저장 ID와 각 sample의
  LAI/기관량/삼각형 면적 대사, 전체 응답 30초 내와 서버/브라우저/DB 정리.
- 12ui 생성 디자인의 실제 이미지/HTML을 통합하고 원 디자인과 실제 화면을 비교한다.
  디자인의 예시 숫자/과밀 수관은 실제 계산 상태로 교체한다.

로컬 데모를 추가하면 개발 서버에서만 명시적으로 실행한다. 수용 시험의 공개
합성 API 응답을 재생하는 고정 fixture이며 실제 DB 내역·새 계산·전체 작기가 아님을
표시한다. 생산 빌드나 운영 API에는 fixture를 자동 제공하지 않는다.
