## 읽기와 같은 결과의 결합

기존 메모리 Bearer·등록 farm/crop 문맥에서 result v2를 선택한다.
기존 v1은 별도 판본으로 유지한다. 새 API의 닫힌 타입·기간/단위·50개 배열과
연구 범위·정확한 result ID/farm/등록을 검사한다. 각 응답은 2 MiB·30초 이내로
읽고 단일 순차 요청을 사용한다. 기존 인증·no-store/redirect 거부를 유지한다.

먼저 최대 8개 sample 페이지를 offset/limit/total/next_offset에 따라 합친다.
모든 페이지의 result ID·최초 recorded_at·farm/crop/batch/zone·status/hold와
전체 manifest/hash는 동일해야 한다. 첫 페이지의 사건은 한 번만 합친다.
전체 sample을 확인한 뒤 공통 척도·표/그래프/3D를 만든다.
진행 중에는 확인한 페이지/시점 수와 취소를 표시한다.
추가 사건은 별도 페이지 탐색으로 읽으며 이미 확인한 sample을 바꾸지 않는다.
한 요청의 30초를 전체 여러 페이지의 완료 시간으로 표현하지 않는다.

다른 ID/계정/등록·재조회·중단/거부·형식 실패에는 이전 결과/장면을 지우고
이전 요청을 취소한다. 늦은 응답도 버린다. 페이지 전체성·중복/범위/순서를
검사하고 완성되지 않은 시계열을 완성된 작기로 표시하지 않는다.
브라우저는 생장 방정식·계수·수지 또는 미래 상태를 계산하지 않는다.

## 표·그래프·3D의 단일 시점

모든 표현은 같은 `result_id + farm + manifest + sample.at`를 읽는다.
선택/자동 재생은 저장 sample의 정수 인덱스만 이동하며 보간하지 않는다.
기관 5개·50개 N/C·LAI·총 과실 C·12개 누적량/두 수지를 서버 단위로 표시한다.
누적 terminal/관리 제거량도 실제 수확·판매 또는 구매 자원으로 이름 붙이지 않는다.

잎 면은 기존 논리 바닥 1 m²·한 면 삼각형 면적 대사를 재사용한다.
모식 배치/지지선은 실제 키·잎 수·재식밀도/도면의 계산 결과가 아니다.
과실 탄소와 개수 상당량은 **구획 1–50의 서로 다른 단위**로 분리해 보여준다.
50개 C 비교 도형과 50개 N 비교 도형은 각 단위의 시계열 전체에서 고정한
공통 표시 척도를 사용하고 표의 정확한 값과 구획 인덱스를 대사한다.
이는 질량/개수 상당량의 3D 도표다. 도형의 높이·위치·색을 실제 열매 크기·
개수·착과 위치·숙기 또는 수확 시점으로 해석하지 않는다.
영 값은 0으로 표시하고 안전한 도형을 만들 수 없으면 텍스트/표를 유지한다.

새 API의 hold는 확인된 과거 sample/event만 탐색하게 한다. 보류 시각 이후
장면은 없고 `last_confirmed`는 별도 진단이다. 관리 후 output sample로
추가하거나 실패 trial을 정상 프레임으로 만들지 않는다.
UTC의 소수 초 hold와 같은 초 sample도 시간 순서대로 비교한다.
확인된 sample이 없으면 숫자/장면 없이 보류와 누락을 표시한다.
합성·미게시·품종 미검증·관문 미평가, 실제 시계열 길이를 항상 구분한다.

## 접근성과 수용

기존 키보드 시점/카메라·HTML 표·모바일/확대·움직임 줄이기와
WebGL 불가/loss/restoration을 유지한다. on-demand 렌더링을 사용하고
GPU/타이머/observer/요청을 정리한다. 12ui-design 및 브라우저 시험 스킬을 적용한다.
새 프레임워크나 도메인 계수를 이 장면 단계에서 추가하지 않는다.

1. decoder/페이지 결합: 같은 원 수치·해시, 512/128 한도·누락/중복/혼합,
   50개 배열/단위·UTC/소수 초 hold·현재 거부·계정 변경/늦은 응답·취소를 확인한다.
2. 실제 도형에서 선택 LAI의 한 면 면적, C/N 표시 좌표·구획 순서와 서버 값,
   0/큰 값·잘못된 도형의 대체·정리를 확인한다.
3. typecheck/build/단위와 집중 Chromium으로 같은 표/그래프/3D 시점·키보드,
   모바일/확대·움직임 줄이기·WebGL 장애와 재조회 거부를 확인한다.
4. 실제 SCRAM 저장 → 표준 HTTPS → 브라우저에서 같은 ID/UTC와 50개 N/C·
   LAI 면적을 대사하고 현재 권리·저장 hold·서버/브라우저/DB 정리를 기록한다.
5. 사용자가 확인할 화면과 검증·미실행·외부 의존성을 보고한다.
   전체 작기/startup·생과·자원/경제·국내 독립 실측과 G0–G4는 별도다.
