# Recorded supply C/N and terminal window v1

`read_supply_terminal_window(directory, access, root_sha256, *, first_frame=0,
last_frame=None)` reads the existing immutable supply artifact with its exact
reader and current file/code/embedded-rights fences. It never turns an old cycle
query into a new authority or executes a growth equation. The return value is a
bounded defensive data projection, not a farm Run or gate decision.

One inclusive, original-index window exposes each original at/phase/index,
Context/CP/material receipt/prefix references and state hash, the50original
fruit-carbohydrate and fruit-number coordinates, exact represented-stock sums and
original exact lifetime terminal C/N. Units are `mg_CH2O/m2_floor` and
`fruits_equivalent/m2_floor`. Fractional model counts are preserved. No individual
fruit IDs, shape, maturity, fresh mass, real harvest, grade, sale or money is inferred.

Checkpoint frames bind their actual stored lifetime. A dense-before frame binds
the validated material receipt's pending lifetime at that exact point. Do not
substitute the last grid checkpoint or a rounded UTC. Adjacent positive-duration
rows are exact nonnegative terminal differences. Equal-time before/after material
rows require exactly zero terminal differences and remain distinct, traceable
zero-duration boundaries. Single-frame windows have no interval and zero total.
Totals telescope to the actual window endpoints without resetting across Contexts.

Reject bool/invalid indices, wrong quantities/layout/units, backward time or
decreasing cumulative terminal quantities, changed source/rights/code and any
late fence failure. Preserve original2MiB output and parent frame/scalar limits.
Recheck source and own code after projection. No cross-request validation cache,
source writes, model/RHS/CLI/DB/network activity or modification of accepted inputs,
model/parameter versions, prior artifacts or existing GUI.

Acceptance: authentic current62-file CAS/38original frames and all50cohort
coordinates, exact lifetime/37adjacent rows including5zero-duration boundaries;
independent high-precision endpoint/delta/telescope arithmetic; first/last/single
windows, malformed selection, source mutation/current and late rejection,
defensive copies and bounded output. Verify separate cold process imports no
growth equations and changes no input, while preserving the old and finite user
previews/WSL limits. Use no new biological coefficient or mass conversion.

The scope is `synthetic_terminal_quantities_only`, G0–G4 `not_assessed`, R2
`not_approved`. Record full source/model/profile/root and code identities and the
original terminal status. Actual harvest classification/CH2O→DM/FW, resource
purchases, economic/market/farm/API/UI integration and biological validation are
separate dependencies.
