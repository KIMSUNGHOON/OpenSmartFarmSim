# 같은 저장 C_i/a/A의 사실적 잎 3D — 연구 v1

상태: [42신규/388관련·Chrome43·별도 공개 미리보기](../research/leaf-carbon-stock-stored-3d-20261026.md)의 소프트웨어 수용. 모사 없는 실제 표시 창/R2는 별도 보류다. [수용된 SDK](leaf-carbon-stock-sdk-v1.md)의 원6조건/102시점만 표시한다.
현재 잎 ID·단면 A를 기존 제작 scaffold의 복엽 실제 삼각형에 연결한다. C_i는 같은 시점의 원 수량/장부·표/그래프다.
탄소량에서 면적/키/과실을 추론하거나 저장하지 않은 중간 성장 상태·새 출현을 만들지 않는다.
줄기1.6m/부착/잎의 pose·형상과 보기 위한 조명은 제작 외형이며 생장 계산의 결과와 구분한다.

원3개 ID의 기존 승인 디자인·PBR 잎/잎맥/그림자·회전/확대를 재사용한다.512개 잎 SDK 경계를 이 제작3잎 renderer의 범위로 확대하지 않는다.
현재 A/C_i/열적 나이·원 LAI/기후·개별/전체 누적량/잔차는 같은 원 index/정확 시각을 따른다.
URL은 scenario/artifact/frame을 결속해 메뉴/새로고침/앞뒤 이동에서 선택을 보존한다. 보류 상태는 이전 장면/표를 남기지 않는다.
재생은 원 시점만 순서대로 선택하며 숨김/유휴에서는 불필요한 draw를 하지 않는다. WebGL 실패 시 같은 원 표를 유지한다.

기존 승인 화면/12ui kit를 시각 기준으로 사용한다. 실제 3D/동적 데이터가 필요한 사용자 지시에 따라
kit의 식물/그래프 raster 대체는 사용하지 않는다. 새 유료 디자인 호출·자산/패키지·기존 farm/API의 기한 연장은 없다.
별도 공개 합성 미리보기만 새 소유 loopback 정적 서비스로 제공하며 기존 원본·외형 서비스/배포를 유지한다.

수용: 원102frame의 실제 leaf ID/A mesh와 같은 시점 C_i/나이·장부/표/그래프/정확 시각을 전부 대사한다.
집중 unit/기존 renderer·SDK·URL 회귀·전체 타입·모듈별 UI build, 실제 브라우저/WebGL·모바일/유휴·동작/원 source 파일을 확인한다.
원 private False/이미 배포된 파일·현재 살아 있는 보호 root와 WSL512MiB/PID·1GiB 합계 한도를 보존한다.
당시4root가 현재도 실행 중이라고 주장하지 않는다. 주앱 전체 build와 모사 없는 실제 창/R2 보류는 별도 증거가 필요하다.
실제 품종/관측·한 작기/생산/자원·경제/자율 비교·farm/제품 CLI·G0–G4는 이번에 승인하지 않는다.
