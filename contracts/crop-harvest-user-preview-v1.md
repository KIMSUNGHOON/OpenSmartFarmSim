# 원 전체 생장·수확의 사용자 미리보기 전환 — v1

2026-10-09, native Codex CLI `gpt-6.1-sol / xhigh`, 재귀 CLI0회.
선행 전체 writer/API/대표3D와 조기 body 종료 보완 뒤 기존 제품 App을 사용한다.
core5는 이 계약, `research/crop-harvest-api-cost.py`의 명시 credential lifetime,
`research/crop-harvest-user-preview.py`, `research/crop-harvest-preview-probe.py`,
`web/e2e/harvest-user-preview-native-smoke.mjs`다. 감독·정확한 소유 전환·접속 자격증명은 private 기록이다.

1. 현재 committed source를 고정하고 원 manifest는 원 frozen Python으로 검증한다.
   같은 원 생장47,809시점/5사건·수확47,813행의 인증 backup을 별도 DB에 복원한다.
   정상 공유 ApiRuntime/current query·읽기 권한과 기존 버전/최초 UTC/원량을 유지한다.
2. 기존 사용자5173/8443/source/dist를 보존한 채 후보5174/8445를 기동한다.
   원 summary/첫·끝 page wire·현재 scope/다른 계정 거부·frontend/실제 자산 bytes와
   현재 웹 source/수용된 불변 빌드 일치를 확인한다. source·입력·manifest/keys를 변경하지 않는다.
3. 후보 수용 뒤 원 서비스 PID/start/boot·argv를 대조해 pidfd SIGTERM으로 종료하고
   원 도구 종료/정리·PG 부재를 확인한다. 후보의 소유 Nginx만 고정 설정 새 판본으로 reload해5173을 연다.
   실제5173 proxy/보호 API를 재확인하고 기존 App의 수확 표/같은 UTC WebGL을 직접 읽는다.
4. 새 기동 handle/현재 controller·서비스·PG identity와0.25초 RSS를 기록한다.
   단일512MiB/명시 소유+보호 트리 합1GiB를 유지하며 그 밖의 WSL 용량을 수용했다고 보고하지 않는다.
   읽기 token은24시간 이내이며 만료 전에 감독 종료한다. private 안내에만 저장한다.
5. 조회 RHS/생성/등록/proof0·공유 권리 파일0·DB counts·원본/FD와 실제 종료·소유 정리를 대사한다.
   계속 실행하는 새 서비스에는 가짜 종료0을 쓰지 않는다. 기동/전환 도구의 종료와 live 서비스 관측을 구분한다.

현재 페이지/수확 수량은 합성 계약 자료의 저장 재생이다. 실제 품종·농장 Run·국내 독립 자료0건,
