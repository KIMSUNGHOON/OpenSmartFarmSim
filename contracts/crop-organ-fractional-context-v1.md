# Fractional individual-organ capture and checkpoint, research v1

`prepare_context(source_context, raw_checkpoint, expected_sha256, time_tolerance_seconds_exact, inputs)` computes the accepted source-bound fractional material point. It captures that actual result and a canonical snapshot of the genuine mixed-organ source context in a new immutable context. It never prepares the after-program as an initial crop or fabricates an older context/checkpoint token.

Capture the source/point/code/profile identities, original selected simulation and development origins, exact point time and original grid position, ordered current C/age/area/anchors, per-organ exact time/air/carbon/age bases, original source and pending continuous transfers, per-kind sequential point costs and exact lifetime point/global books. Original represented prefixes stay distinct from their exact pending sums. New organ flow fields start at zero. Structural carbon is an internal transfer; growth respiration is an outflow. Preserve the accepted exact source-plus-local-plus-point budget composition without an added absolute tolerance.

Consume exactly the original first source event, recording its canonical logical ID, sequence and threshold. The next sequence/threshold follow the original phyllochron. Hold if the selected numerical age has already reached that next threshold; do not skip events or snap the selected time/age. A numerical material-point birth is not a validated physiological emergence observation.

`context_bytes` and `restore_context(root_context, raw_bytes, expected_sha256, crop_directory, stem_directory, access)` bind externally trusted canonical snapshot bytes to the actual original Root and currently accessible source. Validate captured identities, closed source/point inputs, direct state/flow/receipt transitions, exact timing, bases and ledgers without past RHS, point execution or leaf initialization. A trusted hash must come from storage/run evidence; caller self-hashing is not farm custody or authentication.

`start(context)` yields the new typed after-point checkpoint without RHS. Its exact time, phase, event sequence, original grid position, cursor/prefix, saved sample, zero branch transfers and captured pending/point/global books are deterministic. The before/after samples extend the original output prefix exactly once each. `checkpoint_bytes` preserves canonical bytes; `restore_checkpoint` validates the exact captured payload and evaluates only the current RHS once, then rechecks current source/code/profile/rights. It never charges a point again. No remainder advance is exposed in this slice.

Context/response <=2MiB, checkpoint <=512KiB, both inventories <=512, original <=600s/4096 steps and remaining scalar budget32768 are retained along with lower source caps. Late source/code/profile/rights changes hold; failure yields no context/checkpoint. RuntimeError is not converted into an expected hold. No DB, CLI, network or writes; software research only, synthetic model clock, G0–G4 not assessed, no crop/production/economic/recommendation or R2 approval.

Acceptance: actual stem-only/mixed source-bound fractional capture; direct after-state and preserved old/source data, sequential costs and exact global books; next-event consumption and multiple-threshold hold; trusted canonical context/CP restore with zero replay and one current CP RHS, fresh processes, tampered state/IDs/time/flow/unit/bases/ledger/rights/source/code/profile/late/caps, unchanged old GUI/data and bounded WSL resources. Follow with exact original-grid remainder and partition-identical resume, then source-bound carbon-limited geometry and immutable same-state 3D.
