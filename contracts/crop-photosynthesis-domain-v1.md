# 작물 광합성 적용 영역 v1

상태: **원식/영역 검토와 로컬 소프트웨어 수용, 2026-10-04**.
정책 ID는 `vanthoor-bounded-photosynthesis-v1`다.
[유량 계산 계약](crop-growth-research-v1.md), [원식/대안 검토](../research/crop-photosynthesis-domain.md)를
따른다. 기존 모델/프로필을 바꾸지 않고 적분의 지원 영역과 실패 조건을 고정한다.
이 정책의 수용은 품종 초기조건·G0·국내 G2/G3 또는 전체 G1의 수용이 아니다.

## 고정 식과 영역

양의 PAR, 양의 잎 면적 지수 `L`에 대해 다음을 사용한다.

```text
L = sla * leaf_carbohydrates
Ci = etaCo2AirStom * co2
Delta = Tcan - 20
Gamma = cGamma * (20 + Delta / L)
A = Ci / cGamma - 20
supported = (20 * L + Delta >= 0) and (A * L - Delta >= 0)
```

이는 원식의 `0 <= Gamma <= Ci`를 대수적으로 풀어 얻은 조건이다. 계산 상수와
단위는 [고정 참조 프로필](../fixtures/crop-growth-reference-parameters-v1.json)에서 읽는다.
`L`은 m² leaf/m² floor, `Gamma/Ci/co2`는 ppm, 수관 온도는 °C다. 판정 경계의
실수 반올림을 허용하려고 영역을 넓히거나 Gamma를 clip하지 않는다. 경계 부근의
실제 실행은 유량 모듈의 평가 결과와 수치 실패를 보존한다.

- `A > 0`: `L >= max(0, -Delta/20, Delta/A)`이면서 `L > 0`.
- `A = 0`: `Delta <= 0`, `L >= -Delta/20`이면서 `L > 0`.
- `A < 0`: `Delta < 0`, `-Delta/20 <= L <= Delta/A`, `L > 0`.

PAR=0에서는 Gamma를 평가하지 않고 광 동화 0이다. PAR>0이고 L=0이면
Tcan=20°C인 유한한 극한만 받는다. 다른 온도에는 `COMPENSATION_POINT_HOLD`를
남긴다. 위 조건은 단위/유한/비음수 입력·양의 CO₂와 원 계약의 순간 수관
10~34°C·평활 온도 17~23°C 검사를 대체하지 않는다.

## 적분 착수와 중단

명시적 합성 또는 검토된 참조 초기조건/forcing으로 적분 개발을 시작할 수 있다.
실제 Axiany 작기 재현에는 [forcing/초기조건 감사](../tasks/todo.md)의 별도 수용이 필요하다.
일반 코드의 초기 잎 질량을 품종의 측정값으로 등록하거나 필요한 L에 맞춰 늘리지 않는다.

적분기는 다음 계약에서 이 정책 ID·모델/프로필·입력/솔버 판본을 고정하고, 모든
미분 평가와 출력 시점에서 적용 영역을 확인한다. 시간 경계·PAR의 낮/밤 변경과
명시적 제거 사건 전후에도 확인한다. 다음 실패에는 완료 결과를 발급하지 않는다.

1. 작은 수관/온도/CO₂가 지원 영역을 벗어남: `COMPENSATION_POINT_HOLD`.
2. 기관/버퍼가 고갈되거나 음의 상태로 진행하려 함: 별도 고갈 정책의 hold.
3. 평활 온도·기타 지원 범위 위반이나 비유한/수지 실패: 기존 고정 hold.

반환할 실패 증거에는 평가 UTC 시각·단계, 마지막 확인 상태와 실패 입력,
원 오류·정책/모델/프로필·forcing/초기조건 해시를 둔다. 솔버 내부의 시험 단계에서
실패했으면 마지막 확인 시각을 작기의 물리적 고갈 시각으로 바꾸어 표시하지 않는다.
입력을 검토해 새 판본을 만들 수 있지만 실패를 임의 0/최솟값·대체 식으로 이어가지 않는다.
최종 저장 실패의 객체/정밀도/시각 계약은 적분 모듈 착수 전에 확정한다.

## 수용 기준과 사용자 산출물

1. 원 논문 Eq9.22/9.23·저자 코드와 대조하고, 잎 수준 식을 수관에 그대로 적용한
   대안의 원문 경고/새 검증 필요를 기록한다. 검증된 품종 대안 없이 v1 식을 교체하지 않는다.
2. 독립 Decimal 대수 조건과 실제 유량 모듈의 냉/온 수관·CO₂·작은 잎/경계 양쪽·
   낮/밤의 수용/거부를 비교한다. 경계 가까이의 반올림을 생리 오차로 해석하지 않는다.
3. L=1에서 잎 수준 보상점과 일치, Tcan=20에서 유한한 잎 0 극한,
   낮은 CO₂에서 수용 가능한 L의 상한과 중단을 확인한다.
4. 실제 CLI 모델/effort·원문/프로필 해시·검사 결과와 남은 실제 초기조건 hold를 기록한다.

사용자는 원식/대안 판단, 단위가 있는 적용 구간 표, 집중 검사 결과와
실제 품종 입력에 부족한 근거를 확인한다. 생산량·숙기·성장 3D를 게시하지 않는다.

실제 `tests/test_crop_photosynthesis_domain.py`의 **32개**와 기존 유량 시험 86개를
함께 실행해 **118 passed / 0.18초**를 확인했다. 연구 보고서에 명령/범위와
원문/프로필 해시를 기록했다. 아직 없는 적분기의 실패 증거 구현을 수용한 것은 아니다.
