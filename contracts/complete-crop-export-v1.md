# Complete crop research artifact export, v1

Export a trusted [complete research artifact](crop-complete-artifact-v1.md) with
`research/export-complete-crop-replay.py`. Reuse the existing funded-export FD-bound
exclusive writer. Do not change the stored artifact, existing exporter or reader.
Require explicit ownership/access/store/use/transform/display/redistribute=True for
leaf source, stem source and initial-link declaration before creating output and
again before publishing. False remains false. Embedded grants and local file checks
are research-copy authority; external farm custody/revocation and G0–G4/R2 stay separate.

Read the verified reachable graph once. Preserve every raw blob, root, packet,
context, point receipt and NOTICE bytes/hash; exclude unrelated CAS orphans.
For each original frame export a closed DTO with exactly schema_version=
`complete-crop-public-frame-v1`, artifact_sha256, index and frame. The frame retains
its raw CP or explicit CP-less dense snapshot without interpolation, duplicated
quantities or growth calculation. A consumer decodes original C_i/a/A from that
frame's stored vector and uses its original organ IDs/clock/attachments.

The closed `complete-crop-public-fixture-v1` index contains the original research
flags, artifact_sha256, code_sha256, exporter_sha256, output_writer_sha256, basis,
root/packet/notice descriptors, blobs, frames and sample_scalars. Blob descriptors
are path/sha256/bytes. Frame descriptors retain index/at/phase/event_sequence/cursor/
prefix/frame/state/CP hashes and add the DTO path/sha256/bytes. Paths are generated
single filenames; public index/individual files remain ≤2MiB, stored frame/organ/
leaf/scalar and lower source limits remain unchanged. A larger otherwise valid
stored blob is an explicit export-cap hold, not permission to truncate it.

Output is a new absolute nonsymlink path outside source and its ancestors/descendants.
Use exclusive/nofollow writes, FD/path identity and owner/group/mode/ACL/single-link
checks; verify exact file set/bytes after writing. Revalidate current complete source,
all grants, code and output before .index.pending→index.json rename/fsync. No overwrite.
Two new outputs of the same source/code have identical bytes/index. Failure before
publication leaves no index. Post-publication drift does not erase an immutable index;
current readers must reject drift and callers must trust the producer's index hash.

Acceptance: original 12 own-public cases/834 frames and two identical outputs,
raw/DTO/notice/units/time/phase/ID/CP preservation, actual private:false rejection
without output, late source/grants/code/output drift and directory replacement,
partial/publish failure and unsafe/existing paths. Independently measure growth
imports/DB/CLI/network=0, writes outside new output=0, WSL caps and source/private/GUI
preservation. Strict SDK/same-state realistic 3D and agricultural validation follow.
