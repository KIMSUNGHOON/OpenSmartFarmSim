# Stored supply morphology research screen v1

Use the accepted original HTTP SDK and geometry. The chosen12ui candidate C and
its generated responsive prototype are the layout baseline; integrate actual
Three.js canvas and stored data, then close against the original design target.
No crop raster image, fabricated coefficients/quantities, interpolated growth,
new model run or whole-cultivar/production/economic recommendation claim.

The38stored frames drive one selected index, original exact at/phase/IDs, actual
one-sided leaf areas/internode lengths, same-time tables and ordinal history.
Show connected forest, unbound leaves or all without fabricating null parents or
nonzero lengths. Label authored shape/pose and the independent null-root display.
Keep research scope/rights, original terminal hold and G0–G4/R2 explicit.

Persist index/view/panel under this immutable artifact's browser preference key.
Valid URL values take precedence; malformed/out-of-range/obsolete preferences do
not supply data or gate evidence. App-menu navigation and reload retain selection.
Playback visits original frames only, pauses at end/when hidden and creates no
calculation request. Keyboard, responsive controls and retry are accessible.

Verify sources before showing any frame. Loading reports actual waiting only;
failed/retried/unmounted loads abort and clear stale canvas/table/plots. Latest
response wins. WebGL failure clears the canvas and leaves valid source tables.
Use self-hosted assets, on-demand rendering, bounded DPR and complete cleanup.
The fixed Three.js room lighting is baked once to a hash-checked, bounded gzip
RGBA16LE cube-UV texture; the viewer does not compile a runtime GGX convolution.
Keep the MIT notice, pinned generation source/output and original crop geometry.

Build with `node web/build-supply-morphology.mjs /absolute/new/output-directory`.
This validates and copies only the101own-public fixture files, imported assets,
self-hosted fonts and required notices. It refuses an existing output directory.
Serve that directory on loopback and open `supply-morphology-replay.html`.

Acceptance: focused selection/retention checks, whole types/isolated build;
actual browser original38frames/area/length/ID/at/phase, menu/reload, loading/failure/
retry/stale response, mobile/orbit/idle/cleanup, zero console warnings/errors in
normal use, design alignment and original data/rights/UI/WSL preservation.
Finite user preview is a separate task. Product farm/worker/live external rights,
final R2, measured cultivar/season/production/resources/economics/macros/ranking
and G0–G4 approvals remain separate dependencies.
