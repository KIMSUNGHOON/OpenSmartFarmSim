# 자동 출현 원 수치 결과의 서버 계산·서명/현재 조회 — v1

상태: [신규56/관련227·실제 SCRAM2/fresh 수용](../research/crop-leaf-appearance-signed-artifact-20261024.md). 선행은 [현재 farm/완료 parent 결속](crop-leaf-appearance-farm-binding-v1.md)과
[원 appearance 저장/reader](crop-leaf-appearance-reader-v1.md)다.

`LeafAppearanceArtifactAuthority`는 정확한 appearance farm binding·별도 소유 directory/ContentAccess와
명시 key/issuer/key ID를 받는다. 기존 POSIX 0700/0400·nofollow/single-link·SHA/원자 저장과
64MiB/파일 수 상한을 유지하며 parent directory와 동일/상위/하위 경로를 거부한다.
별칭을 해소한 두 경로도 발급/조회마다 고정 참조와 대사한다.
program2MiB/source1MiB/evidence2MiB/binding2MiB·서명128KiB/응답2MiB다.

producer는 현재 prepare→appearance producer1회→원 manifest/전 frame 확인→현재 write 재검사→
원 packet/binding과 새 domain의 signed 증거 저장→마지막 현재 재검사 순서다.
원 parent와 같은1–64시점 상한을 유지한다. 원43blob의 source/준비/생성/내부 population root·33code/12시점/47면적을 보존한다.
서명은 tenant/study·farm binding/원 입력·outer root, parent job/result/root와 최초 calculated_at을 묶는다.
실패는 결과 ID를 반환하지 않으며 남은 private 객체를 게시 Run으로 세지 않는다. 임의 unsigned root attach 발급은 없다.

manifest/frame/replay는 원 파일·서명/현재 farm·양쪽 source 검토/표시 권리를 전후 확인한다.
outer의 source program SHA/크기·정책/초기/프로필 지문·모델/33code·parent/root/원점·초기 정확 초를 결속한다.
준비·생성/내부 root 연결은 원 compute-free reader로 대사한다. 출력 UTC는 같은 등록 기간 안이어야 하고
마지막 프레임은 원 기간 끝과 같아야 한다. 전체 replay를 하나의 현재성 경계/2MiB 안에 반환한다.
최초 result/root/calculated_at와 DTO bytes 의미를 유지하고 조회에서 producer/생장 import/계산·CLI·DB/파일쓰기0이다.
현재 farm 확인을 위한 DB 읽기는 허용한다. 철회·원본/서명/모델/코드·잘못된 tenant/index/용량과
마지막 frame 뒤 변경은 hold이며 부분 결과/다른 root로 대체하지 않는다.

이 서명은 합성 소프트웨어 계산과 lineage 증거다. 실제 품종/초기 관측·생물학적 검증·G0–G4 승인,
기존 jobs의 접수/worker/원자 게시·보호 HTTP/사용자 자동3D 수용은 후속이다.
서로 다른 파일/DB/resolver의 원자 snapshot은 주장하지 않으며 후속 게시기가 현재 검사를 다시 수행한다.

수용: 실제 producer1회·원 outer/inner/preparation/43blob/12frame·47면적과 parent 보존,
잘못된 초기 면적·현재/늦은 철회·서명/파일/원본·코드/참조·범위/한도 거부,
실제 SCRAM/fresh manifest/frame/replay의 import/계산·CLI·DB/파일쓰기0·원 시각/ID·행/FD·3root/WSL/소유 정리다.
