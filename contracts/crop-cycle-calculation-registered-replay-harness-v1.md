# 같은 등록 DB의 계산→게시→보호 API→3D 검증 구성

2026-10-08 KST. 현재 native Codex CLI `gpt-6.1-sol / xhigh` 판단이며 재귀 CLI는0회다.
[완료 게시](crop-cycle-calculation-registered-terminal-publication-v1.md) 다음의 소유 합성 통합 시험이다.

기존 농장/DB/입력/서버 artifact와 첫 계산 전 원 감독·별도 DB key 선언을 유지한다.
계산을 완료하고 fresh Python이 게시한 같은 row를 기존 결과 증명/현재 query·보호 설정 loader·
실제 HTTPS·현재 App/SDK/3D에 연결한다. 다른 DB나 기록 응답으로 교체하지 않는다.
새 결과 증명 key는 서버/DB key와 다르며 사설에서만 사용한다. TLS/시험 토큰은 계산 뒤 발급한다.

작은 관리 사건 입력의 실제 계산과 게시 뒤 전체 원 출력/사건·UTC를 확인한다.
현재 화면에서 원50개 C/N·LAI·저장 시점의 도형/표/그래프와 관리 사건 전후/제거값을 대사한다.
현재 권리 철회/복원·계정 거부·현재 장면 제거, GET RHS/계산/증명 발행/게시0,
완전한 HTTPS 본문30초/2MiB·no-store와 요청 직렬 처리, 실제 종료·source/FD·DB/비밀/PG/
HTTPS/Vite/Chromium 정리를 확인한 뒤 작은 통합 구성을 수용한다. 원 명령 상한600초다.

후속 전체166일도 같은 DB/farm/artifact를 전체 원량/수지 대사→게시→API/3D까지 유지한 뒤 정리한다.
브라우저에는 처음 두 범위 이하와 최대8사건의 원 참조만 전달하며 전체47,809개 행을 쌓지 않는다.
대표 장면의 수용을 전체 프레임의 브라우저 대사로 표시하지 않는다. 전체 원 행 검증은 별도 streaming 비교다.
현재 UI의 순차 범위 탐색은 유지하며 대규모 결과의 직접 범위 이동은 후속 사용성 작업으로 기록한다.
원9시간 상한에 준비/검증/연결/정리를 포함한다. 작은 시험으로 전체 실행/조회 성능이나 날짜를 예측하지 않는다.

이는 G1 독립 제품 CLI나 실제 품종/현장/생과 생산/경제·G0–G4 수용이 아니다.
