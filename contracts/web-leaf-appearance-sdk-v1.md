# 자동 출현 저장 결과의 strict SDK — 연구 v1

상태: [신규53/관련53·타입/번들·실제 HTTP 수용](../research/leaf-appearance-sdk-20261024.md).
[공개20파일](crop-leaf-appearance-export-v1.md)의 root/index SHA에 고정한다.
새 UI/geometry는 별도 수용이다. 기존17파일 client/화면은 보존한다.

`loadLeafAppearanceReplay(signal)`은 상대 leaf-appearance-replay 경로의20파일만 GET한다.
cache=no-store/redirect=error/credentials=omit와 각2MiB·명시 byte/hash·취소 신호를 적용한다.
root/index와 원 source/전체 준비·생성/내부 root/stem의7근거 bytes를 검사한 뒤 DTO12개를 모두 검사한다.
모든 파일의 byte hash가 원 저장 수치/근거의 인증 경계다. 알려진 신뢰 root를 새 농장 승인으로 승격하지 않는다.

`decodeLeafAppearanceFrame(value, descriptor, root, populationRoot)`는 위 인증된 문맥의 닫힌 DTO를 검사한다.
원 모델/코드·양쪽 권리·root/내부 root/입력·준비·정책/프로필 SHA와 원 descriptor/UTC/초기·최종 state chain을 대사한다.
source/준비/생성의 닫힌 최상위 컨테이너와 정책/핵심 결속을 검사하고, 전체 원문은 위 byte hash로 인증한다.
Python float canonical JSON을 JavaScript JSON으로 재해시하거나 수치 모델을 구현하지 않는다.

잎 선언 메타데이터는 검증된 새5개 원 ID/부착/정확 출현 초/curve SHA를 고정한다.
같은 UTC에 이미 출현한 목록만 허용하며 누락/중복·미래/다른 부착·단위/음수/비정규 유리수를 거부한다.
형식 검사는 바이트 인증을 대신하지 않는다. 정상 범위의 숫자가 바뀌어도 loader의 원 hash 검사가 거부한다.
원 stem decoder/공통 IO·모델 문자열은 재사용하지만 이전3→6잎 fixture의 선언/표식을 새 계산에 사용하지 않는다.

전체 정상 조회 후 typed frames와 원 root/정책을 반환한다. 중단/누락/변조 때 partial frames나 대체 데이터를 반환하지 않는다.
SDK는 생장·출현/면적식·POST를 실행하지 않는다. 실제 사용자3D/메뉴/reload·권리 제거는 후속 UI 수용이다.

수용은 부재 RED→타입/집중 unit, 실제20파일 GET/12시점·47면적·원 UTC/ID/해시/반환 값,
각 파일 변조·형식/상태 혼합·중단/2MiB·기존 client 회귀와 원 자료/WSL/3root·소유 정리다.
실제 browser/제품 runtime·농장/독립 품종 자료·G0–G4/생산·경제·자율 비교 보류는 유지한다.
