## Adoption and hold register

- **Derived forcing and control provenance:** In this synthetic-only v1 accepted trace, generic sourced numeric inputs and saturation-law coefficients admit `measured`, `literature`, or `assumed`; v1 rejects `derived` for those records even if derivation metadata is supplied. Heater availability is a sourced dimensionless boolean (`unit="1"`) with `measured` or `assumed` origin, basis, and version. Only `outdoor_humidity_ratio` and `solar_gain` are derived sourced inputs: each requires a rule reference, explicit rule version, and nonempty immutable input record ID list. A future derived generic input or coefficient needs a new contract version and deterministic calculation rule. JSON Schema checks these shapes; the later fixture, engine, and server must resolve record IDs, verify chronology and equations, and establish that the basis and rights claims are genuine.
- **Synthetic input review:** This accepted-trace schema requires every `source_records` item to say `synthetic=true`, project QC `pass`, self-authored use/display/redistribution rights `allowed`, and provider QC other than `fail`; it also requires author, source locator/fixture ID, observation and publication/availability/retrieval times, vintage/revision, original unit, normalization rule reference, raw SHA-256, and reviewer. `synthetic_input_review_id` names the review of those self-authored input claims and their immutable fixture/manifest links. The server checks their truth, rights ownership, hash, normalization, and QC evidence before calculation/replay. A structural schema pass or a chosen coordinate is not an actual external-source G0 pass or a field-accuracy claim.
- **Actual-source G0 hold:** An external weather or facility record needs exact source URL/product ID, observation and publication times, `available_at`, retrieval time, vintage/revision, original units, provider QC distinct from project QC, raw SHA-256, use/display/redistribution rights, and reviewer. The source-specific G0 path must verify those facts and applicability before any actual-data run; this synthetic-only v1 schema cannot accept such a record. Field-accuracy claims additionally need later gates and independent local measurements. A prose citation is not G0 approval.
- **CLI evidence:** The preceding exact `gpt-6-sol`/`xhigh` research outputs are `/tmp/ossf_thermal_probe_result.txt` and `/tmp/ossf_thermal_crosscheck_result.txt`. The correction used `codex exec -m gpt-6-sol -c 'model_reasoning_effort="xhigh"' --sandbox workspace-write -o /tmp/ossf_thermal_behavior_fix_result.txt -` with its prompt on stdin; the session made the contract edits and recorded the RED test. That session also attempted a nested CLI invocation, which failed with `workspace routing discovery failed`; it was interrupted after the files were independently checked with 29 passing focused tests. The nested failure supplied no review or source approval. These temporary logs are process evidence, not approved parameters or G0 records.
- **Parameters:** No numeric `C_eff`, `M_da`, `V`, `K_env`, `c_da`, `lambda`, `R_da`, `R_v`, `A_floor`, `f_abs`, `F`, `E_canopy`, ground flux, setpoint, or delivered heater capacity is adopted by this document. Each fixture must state value/unit/origin/basis/version. Literature values cannot be transferred to a site without applicable evidence.
- **Numerics and thermodynamics:** The exact saturation-pressure law, coefficients, domain and version; solar interval semantics; fixture step duration; residual and step-convergence tolerances and rationale are unresolved until a fixture is registered. No arbitrary numeric threshold is supplied. The trace is held if any are absent. Surface condensation and latent return require a new model and evidence; an undersaturated bulk state does not clear a field-accuracy hold.
- **Claims:** A reviewed self-authored synthetic fixture can test G1 calculation and replay contracts, even when it carries a chosen coordinate. Actual external weather/facility data remain at real-source G0 hold; local accuracy additionally needs independent G2 field validation. Local crop measurements, surface temperatures, delivered-heat or purchased-energy metering and efficiency/COP, G3 crop/economic evidence, and G4 deployment and rights proof remain unresolved. Never promote a synthetic trace to growth, harvest, purchased energy, margin, or candidate ranking.
