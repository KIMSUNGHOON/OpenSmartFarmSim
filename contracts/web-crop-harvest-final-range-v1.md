# 저장 수확의 마지막 범위 이동 v1

[기존 수확 화면](web-crop-harvest-view-screen-v1.md)에 작은 탐색 동작을 추가한다.
현재 화면은3행씩 조회하며 긴 작기의 마지막 범위를 직접 여는 동작이 없다.
core는 이 계약, `web/src/HarvestReplay.tsx`, `web/e2e/harvest-replay.spec.ts`다.

- 현재 서버가 검증한 전체 행 수로 마지막3행 페이지의 시작 offset을 구한다.
  0행이면0, 그 외는 `floor((total-1)/3)*3`이다. 실제 끝의1–3행만 조회한다.
  페이지 경계를 넘거나 중간 범위를 모두 다운로드하지 않는다.
- 기존 `load`/SDK·현재 권리/부모 결속·직렬화 검사를 그대로 거친다.
  새 조회 시작은 이전 수확 표시를 지우고 권리 거부는 부모 생장/수확을 함께 지운다.
  원 수량·단위·UTC와 전체 저장 합계를 재계산하지 않는다.
- ‘마지막 수확 범위’는 기존 범위 탐색 안의 키보드 버튼이다.
  현재 offset이 마지막 페이지면 비활성화한다. 기존 모바일/확대 글자 줄바꿈을 유지한다.
- 기록 응답 회귀로 키보드 직접 이동·원 행/단위·끝 경계/이전 복귀·현재 권리 거부를 확인한다.
  그 시험은 UI 계약 증거다. 실제 원 전체 작기의 마지막 생장 시점/수확 범위는 별도
  HTTPS/WebGL에서 원 index/UTC·ID/부모·수량과 대사하고5root/원본·WSL 상한/정리를 확인한다.

새 UI 사용자 적용·전체 U1과 실제 품종/생산 예측·G0–G4 수용은 별도다.
