# 원 저장 출현 잎과 같은 UTC의 3D — 연구 v1

상태: SDK/화면 구현 후보. [불변 population](crop-leaf-population-artifact-v1.md)의 공개17파일과 compiled root/index·원 선언 메타데이터만 사용한다.

원 파일 bytes/SHA·원 result/binding/stem ID·모델/코드/권리·단위/정확 출현/나이·선언 개수를 확인한 뒤 표시한다.

표시 면적은 기존 제작 단면 소엽 삼각형의 실제 instance/world 면적에 대응하며 relative1e-9 이내다.

타입/unit·집중 CI/build/audit와 실서비스 runtime/사용자 URL이 확인돼야 배포 수용을 체크한다.
