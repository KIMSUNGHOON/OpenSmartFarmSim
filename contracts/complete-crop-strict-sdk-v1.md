# Complete crop research replay browser SDK, v1

Read the accepted [complete export](complete-crop-export-v1.md) from a caller-supplied
trusted immutable root/index anchor, or the separately pinned own-public scenario
registry. A downloaded index is not its own authority. No generated numbers, crop
ODE/length/initialization, interpolation, area-to-mass inversion or gate promotion.

Verify closed versions/fields, code sets, explicit scientific holds, source and
initial-link rights, root/packet/raw graph/context/point/NOTICE and every DTO by
original bytes. Reuse pure wire parsing so Python floats are not reserialized to
compute subtree hashes. Reject invalid UTF8, duplicate JSON keys, depth>64, unsafe/
duplicate paths, individual files/index>2MiB, aggregate download>64MiB, >4096 raw
blobs/512 frames/organs/leaves/32768 sample scalars and source lower-cap violations.
A larger valid export is a client-cap hold, not truncation or a lower source limit.

Validate source selection/epoch, actual programs and ordered leaf inventory, original
CP vs CP-less dense candidate vs fractional CP, context/history/seed and output
cursor/prefix, exact times and phases, original organ/attachment/birth references,
length-point receipts and stored quantity units/state/ledger QC. Preserve the
original raw frame and decode C_i/a/A from its original107+3n vector for display.
Math on stored evidence is QC; no growth calculation or biological approval occurs.

Return independent copies. Cancellation must be checked before/after reads and
before return; latest-request control discards an older response even if its fetcher
ignores abort. HTTP omits credentials, refuses redirects, disables cache, and limits
streamed bytes. No shared mutable decoded cache or writes/POST/CLI/backend effects.

Acceptance: all12 scenarios/834 frames and4732 original files, raw hashes/CP/dense/
context/rights/notice/geometry and decoded13788 leaf quantities; invalid wire and
rehashed semantic mutations, cancellation/latest/defensive copy; whole web typecheck
and isolated SDK build, fresh actual HTTP replay with original file preservation,
WSL caps and prior UI/private/source proof. Realistic3D/browser display, external
farm authority, actual cultivar/local measurements and G0–G4/R2 remain subsequent.
