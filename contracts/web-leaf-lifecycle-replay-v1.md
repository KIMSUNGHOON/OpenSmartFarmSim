# 같은 UTC의 잎 생장·제거 연구3D — v1

상태: [소프트웨어 범위 수용](../research/leaf-lifecycle-stored-replay-20261024.md). [SDK](web-leaf-lifecycle-sdk-v1.md)의 두 자체 합성 저장 결과를 사용한다.
`leaf-lifecycle-replay.html`은 기존 사실적 제작 외형/장면·배치/폰트를 재사용한다.
실제 품종 형태나 한 작기/생산·수익·추천을 제공하지 않는다. 고정 과실이나 임의 생장/제거 애니메이션을 붙이지 않는다.

현재 active만 같은 원 UTC/면적으로3D·표/그래프에 표시한다. 제거된 잎은 마지막 면적/나이·원점 이후 정확 제거 초,
pending은 예약 ID/부착·정확 출현 초로 별도 설명한다. 저장 합계를 수정하지 않는다.
단면 소엽 삼각형 면적은 현재 잎의 원 면적과 대사하며 잎자루/줄기 면적을 합치지 않는다.
제작 각도는 원 부착 마디의 sequence로 고정해 다른 잎의 제거로 살아 있는 잎의 방향이 바뀌지 않게 한다.
명시 빈 잎 목록은 줄기만 만들며 고정 외형 잎으로 대체하지 않는다. 누락한 binding의 기존 제작3잎은 유지한다.

선택 scenario/artifact/frame을 URL에 묶어 메뉴/새로고침·뒤로 가기에서 복구한다.
시나리오 변경은 같은 저장 시점에서 비교하며 이전 자료를 로딩/오류 중에 표시하지 않는다.
재생은900ms마다 다음 원 저장 시점으로 이동하고 끝/사용자 탐색·시나리오 변경/숨김 때 멈춘다.
중간 수치/자연 낙엽·생물학적 노화·수확/LAI/질량을 추정하지 않는다.

권리/hash/파일 오류는3D/표를 제거해 보류한다. WebGL2 불가 때는 보류 문구와 원 표/시점 탐색을 유지한다.
모바일/키보드·그래프의 원 시각/면적·유휴 렌더0과 자원 해제를 확인한다.
12ui는 기존 승인 target을 유지해 대조하며 실제 WebGL/원 수치를 래스터 식물·예시 숫자로 바꾸지 않는다.

수용은 geometry/복구 집중검사와 실제 브라우저의 원24시점/94추적 상태·현재 면적/단면 삼각형,
제거 마지막/예정·시나리오/메뉴/reload/재생/모바일/키보드/hold/WebGL·원 화면/자료 보존이다.
기존 서버 정적 경로에 새 판본/entry만 추가하고 backend/DB·키/기존 HTML·결과를 보존한다.
독립 실제 농장/관문·제품 실행 연결과 최종 사실감 R2는 별도다.
