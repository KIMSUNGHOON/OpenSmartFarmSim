# 저장 수확 표와 기존 생장 3D 화면 — v1

2026-10-09 KST. native Codex CLI `gpt-6.1-sol / xhigh`, 재귀 CLI0회.
선행 [순수 결속](web-crop-harvest-growth-binding-v1.md)을 실제 웹의 현재 계산 생장 범위에 연결한다.
core5파일은 이 계약, `web/src/HarvestReplay.tsx`, 기존 `CycleCropReplay.tsx`의 명시 연결,
`web/src/HarvestReplay.css`, `web/e2e/harvest-replay.spec.ts`다.

## 수용 기준

- 현재 API/계산 부모/농장에 속한 수확 결과 ID를 사용한다. 자동 추측/새 계산 없이 기존 SDK로
  summary와 최대8행 page를 순차 조회한다. 각 새 조회는 앞선 취소 요청의 settlement 뒤 시작한다.
  선택/계정/부모 변경·취소·unmount는 늦은 응답을 표시하지 않는다. 새 요청 시작 때 이전 수확 값은 지운다.
- 닫힌 DTO와 원 source/hash/상태·같은 UTC/위치 대사는 선행 함수를 재사용한다.
  현재 읽은 부모 sample 범위의 정확한 UTC만 기존 3D 선택으로 연결한다. 미대응 사건은
  현재 범위에 대응 시점이 없다고 표시하고 새 sample/형상/숙기를 생성하지 않는다.
- 원 제거 구간/사건·배정 목적별 수량과 단위/정확 분수·미배정·합성 관측 비교를 표시한다.
  전체 저장 합계는 명시적으로 접힌 별도 영역이며 현재 부분 범위와 구분한다. 원 수량을 합산하거나 재계산하지 않는다.
  계산 hold·합성/가정/관문 미평가를 보존한다. 원문 ID/hash는 접힌 상세 영역에 둔다.
- 현재 수확 조회의 권한·원본/결속 실패는 수확 값과 기존 부모 3D/표를 제거하고 오류를 표시한다.
  재조회는 현재 서버 검사를 거친다. 이미 받은 화면의 권리를 계속 감시한다고 주장하지 않는다.
- 키보드 표/동일 UTC 선택·390px 모바일·큰 글자·가로 표 스크롤과 HTML 대안을 검증한다.
  집중 Chromium의 원 수량/시간/단위·부분 범위/전체 합계·잘못된 부모/권리·취소/늦은 응답·
  기존 생장 화면 회귀와 웹 단위/타입/빌드·WSL 소유 자원/정리·원 종료를 기록한다.
- 12ui 후보를 직접 확인해 선택하고 승인 HTML/LayerDoc를 기준으로 구현·마무리 비교한다.
  테스트에서 metadata/시각을 맞춘 소유 합성 응답은 형식 증거다. 실제 공동 DB/HTTPS/WebGL 증거로 표시하지 않는다.

## 후속

화면 자식 뒤 작은 실제 같은 DB/API/대표 WebGL와 전체166일 질량 부하는 각각 후속이다.
그 전에는 view/replay 부모를 체크하지 않는다. 실제 자료/독립 농장 검증·G0–G4,
생산/미래 마진/추천·운영 수용 보류는 유지한다.
