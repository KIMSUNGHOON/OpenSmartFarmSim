# 합성 저장 형태의 3D 재생 — v1

상태: 구현/수용 전. [불변 artifact](crop-morphology-research-artifact-v1.md)의 자체 합성 결과만 쓴다.
농장 Run·현재 원천 권리/검증된 품종 모델로 게시하지 않는다.

## 연결

공개 export는 저장 원 root/입력·각 typed DTO를 재조회하고 명시 redistribute=true를 확인한다.
조회 과정에 생장 모듈/계산은 없다. index는 원 root/program SHA, 판본/수식 출처·권리와
프레임별 bytes/SHA·원 result SHA/UTC를 보존한다. 브라우저 번들에 신뢰 index SHA/root SHA를 고정한다.
URL로 임의 입력/실제 농장 데이터를 받거나 다른 시나리오의 LAI를 합치지 않는다.
한 번에 한 요청·제한된 bytes의 원 JSON·SHA와 scope/관문·같은 UTC/ID·기관 순서/길이 단위를 확인한다.
틀리면 3D/표/그래프를 보류한다. 합성 fixture를 실패의 대체 데이터로 쓰지 않는다.

저장12시점(명시 합성 하루,2시간 간격)을 순서대로 재생한다. 재생은 저장값 선택이며 새 계산/실시간 작업 진행이 아니다.
원 기관별 길이를 미터 축에 매핑한다. 줄기 반경/표면/솜털·직선 축과 고정3개 복엽은 제작 가정이다.
잎의 크기/개수·잎/화방 분류, 실제 식물 키·과실·숙기/수확을 계산값으로 만들지 않는다.
기존 외형 참고 화면과 기존5173/5174/5175 자산을 보존한다.

## 수용

타입/단위/해시·모델 호출 없는 export/typed 소비를 대사한다.
실제 WebGL 첫/마지막·기관 수/길이와 같은 UTC의 표/그래프·이전/다음·재생/일시정지·원 ID를 확인한다.
3D geometry가 저장된 절간 길이를 쓰는지 수치로 검사하고 고정 잎 수를 확인한다.
네트워크 GET만·중복 요청0·오류/권리 실패/잘못된 hash 때 보류·WebGL 대체/모바일/키보드를 검사한다.
화면/소스/산출물 hash와 원6서비스·WSL 상한을 기록한다. 최종 사실감 수용/실제 작기 검증은 별도다.
