# Authored farm review completion v1

Status: internal software contract after [authored review admission](farm-authored-review-v1.md). A successful `collection_review` job is not itself a release or an accepted Run.

`AuthoredReviewCompletionVerifier` receives the tenant, immutable review job ID and expected registration SHA-256 from a trusted caller. It requires the exact authored review service and signed execution verifier. It rereads the tenant-scoped completed job, canonical input, current registration/source rights and pins, original snapshot, signed DecisionContext, publication, final server decision, CLI invocation, outcome, sealed capture and stored artifact. The server-generated artifact must bind the same input, registration, candidate, code/context and both trace hashes. It requires `gpt-6-sol` with `xhigh`, a successful zero-exit invocation, and the independent execution attestation against the pinned CLI executable and environment. The authored input's `base_snapshot_id` is the attested original snapshot; legacy review inputs retain their `snapshot_id` rule.

The verifier checks submission, capture, decision and publication order and rereads the job and current authored input after the attestation check. It returns an immutable proof with input, source registration, farm/numeric/rights/binding hashes, original source and snapshot, signed context and temporal scope, candidate, code, two traces, artifact, decision/capture IDs, attempt and decision time. Its canonical proof digest is a handoff identifier for a later independent release; it is not a release signature. Any missing or changed link returns a generic hold without publishing a Run.

The [software verification](../research/farm-authored-review-completion-implementation.md) uses a test double for the CLI and a synthetic signing key. Actual product CLI execution, independent reviewer approval, authored snapshot release, Run publication, 3D connection, G1 and G4 remain separate gates. The review does not validate farm parameters, crop growth, energy purchases, forecast margin or crop ranking.
