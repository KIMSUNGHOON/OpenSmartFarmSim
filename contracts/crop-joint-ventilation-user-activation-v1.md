## 동시 실행 선행 수용 — 2026-10-12

[수용 기록](../research/crop-joint-ventilation-user-capacity-20261012.md)의 현재 소유 미리보기는
같은 비밀 잠금 파일로 농장 등록의 중첩 검증을 직렬화한다. 대기는10초로 제한하고 실제 역할 제한8을 유지한다.
작업자는 custody 세션 진입 전 잠금 경합을 최대30초 기다린다. 진입 뒤 오류는 원 처리로 전달하며
이미 들어간 계산/저장 구간을 재실행하지 않는다. 현재 입력/권리/임대 검사는 원 경로를 따른다.
소유 자식은 pidfd로 정지·timeout 후 강제 종료/회수하며 다른 서비스·로그·DB 보존 정리를 계속한다.
실제 두 독립 소비자와 HTTPS 관측자, 원 수치/UTC·권리 철회·현재 사용자 데이터/두 주소 복구를 확인했다.
현재 사용자 WebGL과 다중 사용자 운영 용량은 각각 후속 수용으로 평가한다.

같은 시각의 RSS 구성·Node heap/external을 계측하고 중복 검증 감독을 합치는 최소 경로를 먼저 평가한다.
