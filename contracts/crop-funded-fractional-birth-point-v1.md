# Declared material jump at fractional candidate time, v1

This operator is the first boundary of `funded-air-fractional-event-continuation`.
It applies the existing explicit structural-growth policy at the exact selected candidate
time without making an original-v1 context/checkpoint pretend to have a different grid.
It creates no resumable checkpoint, spatial attachment, physiological emergence law or gate approval.

`prepare_fractional_birth_context(leaf_directory, stem_directory, access, **selection)` calculates
the [validated candidate](crop-funded-event-state-v1.md), captures immutable program/anchors/
previous applied event IDs/profiles/code and source selection, and returns an internal handle.
It accepts no caller-supplied candidate vector. There is no public handle deserialization in this
version. Python handles are not farm custody/signatures; trusted external storage/restore and
new checkpoint ownership remain the next contract. Snapshot source use/transform/display grants
are checked again for each application; current farm/source review remains a separate parent gate.

`apply_fractional_births(context, inputs)` uses closed synthetic inputs: schema
`funded-fractional-birth-point-input-v1`, input ID, the existing structural policy, prepared
context SHA, candidate calculation SHA, original reduced exact elapsed seconds, original floor
and explicit events. Each event declares ID/attachment ID/incoming temperature and complete new
leaf parameters/zero age/positive independent carbon/F(0). Duplicate current or previously applied
source event IDs and existing leaf IDs are held. Only applied past source events are considered;
future stored plan points are not silently adopted. Actual stem binding remains declared-only.

The new point uses the original `_new_leaf`, `_fund`, `_rounded`, `_quantity`, `_balance` and RHS
arithmetic from the [accepted material point](crop-leaf-funded-birth-point-v1.md). It preserves old
blocks/anchors and uses original `cLeafG`, heat capacity/reference temperature and common floor.
Only buffer/U104 change in the first107 values. New age/A/C blocks are appended with zero age,
canonical positive F(0), and independently declared carbon. It charges structural carbon and
growth respiration once against the unchanged prepared before-state, and records incoming
capacity/sensible heat separately from continuous flows. No default seed mass, SLA inversion,
respiration heat or new agronomic coefficient is introduced.

Current/after RHS evaluations are one each. The same exact time is preserved in new fractional
snapshots with no invented integer step index. Original curve residual anchors and source
prefix/global/segment/point ledgers remain in the captured candidate; point flows/balances are
separate. Repeated evaluation is deterministic over the same immutable input, not a second
adoption into a changing state. Exactly-once checkpoint adoption and cross-new-history replay
prevention belong to continuation, not this stateless point evaluator.

Inputs, captured context and output are each at most2MiB; resulting leaves at most512.
Existing lower component input/output byte caps also apply. A512-leaf request is not
guaranteed to fit those caps for every legal identifier/metadata size; preserve the actual
capacity hold and the unchanged request rather than shorten identifiers or raise a cap.
Validate source/code/profiles/closed fields/time/IDs/floor/units and before/after domains.
Require whole C/buffer/new stock/U/capacity point balances under the unchanged original ULP budgets.
End source fences reject late code/rights/source changes. Failure returns no result/checkpoint,
never a partial point. No past advance, old context/token fabrication, DB/CLI/network/write.
The calculation stays `software_research_only`, `G0_G4=not_assessed`.

Acceptance: actual fractional root/funded contexts and original same-time blocks/anchors/prefix,
old whole-grid arithmetic equivalence on original vectors, independent Decimal carbon/heat,
single/batch and resulting512, failures and late sources/rights/limits, deterministic copies
and resource accounting. Next: a separately versioned fractional checkpoint with combined
global/segment/point ledgers/cursor/phase and one-time adoption, followed by original-grid remainder,
split-resume equality, immutable results and the source-bound same-state realistic3D path.
