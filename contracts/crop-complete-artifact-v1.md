# Immutable complete crop research artifact, v1

The producer takes actual complete-prefix segments and calculates their accepted
bound packet. It stores the original leaf/stem CAS blobs, canonical context bytes,
packet and canonical point request/response receipts for every rendered internode.
Reuse the existing POSIX content store and its0750/0640, single-link, byte/file limits.
No database or tenant/farm Run authority is introduced. Publish the root last after
read-only graph checks and current source/context/code fences. Retries with the same
inputs/code yield the same root. Failure before publication may leave unreferenced
blobs, but no completed root. A post-publication file/code drift fails the final
fence and every subsequent read; it does not erase an immutable published root.

The root pins exact code versions, source/packet/context/geometry descriptors, frame
order/UTC/exact offsets/phases/event/cursor/prefix and original state hashes.
Keep CP-less numerical candidates distinct from original and new checkpoints.
State/C_i/a/A and transfers/ledgers retain one authority in the original CP; the
dense candidate alone has explicit composed quantities. Do not normalize/rewrite
checkpoint bytes or turn self-hashes into approval.

The reader imports only file/shape/QC readers, not growth/ODE/point/initialization
modules. It checks current stored files/code/source grants, schemas, units, exact
time/order/prefix/context lineage, source and point receipt links, state/leaf/parent
inventory and recorded conservation bounds. Arithmetic consistency checks on stored
evidence are QC, not an ODE/length recalculation. Return the same values and explicit
scientific holds. No DB/CLI/network/write or past simulation on read.

These are self-contained research copies with current local file/embedded grant
checks. External farm rights/revocation, trusted root publication/signature, actual
runtime review/admission and G0–G4/R2 remain separate. A caller must obtain the root
hash from a trusted producer/run record; an arbitrary replacement root cannot prove
agricultural correctness or custody. False redistribution remains false; export is
a subsequent explicit boundary.

Caps: root/packet/context each≤2MiB, point receipt≤64KiB, source blob≤16MiB, store≤64MiB/
4096files, ≤512frames/organs/leaves and ≤32768sample scalars. Existing lower caps and
the preserved512-leaf RHS hold remain. Source/rights/code/file drift or partial/
malformed/rehashed inconsistent content holds, with no stale successful response.

Acceptance: actual producer+independent cold reader, original raw CP/candidate/context/
source/notice and exact same leaf/geometry/quantity values, root-last/retry/partial
failure, tampered units/order/parent/receipt/context/source/rights/current code and
late file policy, zero growth imports/DB/CLI/network/write on read, and WSL/preservation
evidence. Export/strict SDK/same-state realistic3D and biological/production validation
are subsequent work.
