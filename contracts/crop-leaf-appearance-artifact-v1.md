# 자동 출현 원 입력과 계산의 불변 저장 — 연구 v1

상태: [producer 신규34/관련315·실제43blob 수용](../research/crop-leaf-appearance-artifact-20261023.md).
무계산 reader/3D는 후속이다. 선행은 [자동 출현 program 준비](crop-leaf-appearance-program-v1.md)다.
별도 소유 디렉터리의 기존 POSIX blob 저장기를 사용한다. DB·서명·농장/현재 권리 게시 승인은 발급하지 않는다.

## 한 번의 계산과 완료 경계

`produce_leaf_appearance_artifact(directory, access, stem_directory=..., program_raw=...)`는
canonical 자체 합성 원 입력을 준비하고, 생성 program으로 기존 population producer를 실행한다.
원 stem 디렉터리와 출력은 달라야 한다. 원 입력/모든 원본14파일과 기존 계산 파일을 수정하지 않는다.
내부 계산 root는 기존 프로토콜이며 자동 출현의 완료 root와 구분한다.

새 `leaf-appearance-research-artifact-v1` 완료 manifest는 원 source program SHA/크기,
전체 preparation SHA/크기, 생성 program SHA/크기, 내부 population root,
원 stem root/program, 권리·모델/33소스 지문·UTC/초기/최종 state SHA·시점 수를 묶는다.
preparation은 원 정책/프로필·초기 결속과 파생 사건/선언의 전체 증거를 보존한다.
입력/증거/manifest는 각각2MiB 이내다. 시각/무작위 ID를 새로 넣지 않는다.
같은 원 bytes/원본/코드의 재시도는 같은 root·파일·metadata를 유지한다.

producer는 내부 원문/12frame·binding을 기존 무계산 reader로 검사한다.
게시 직전 준비를 다시 대사하고 모든 내부/복사 원본 bytes와 원 source/준비 bytes,
원본/현재 소스 지문을 재확인한다. 늦은 원본·코드·증거 변경이나 저장 실패 시
새 appearance 완료 root를 게시하지 않는다. 이미 저장된 내부 계산/부분 blob은 자동 출현 완료가 아니다.
명시 권리의 누락/거절은 보류하며 redistribute=False의 내부 저장은 허용한다.
농장 서비스의 실제 동적 철회는 이 파일 producer의 수용으로 대신하지 않는다.

표식은 software_research_only/synthetic_crop_math_only/not_assessed,
synthetic_model_clock_not_observation/synthetic_software_fixture_only다.
leaf_count는 computed_from_explicit_phytomer_policy_v1이며 기존 실제 수치를 보존한다.

## 이번 수용과 후속

부재 RED→실제 원14파일에서 새43blob/12시점·47면적·3→5잎과
기존 생성 program/계산 root의 동일성, 같은 입력 재시도/기존 root 보존을 확인한다.
초기/권리/원본/코드/파생 증거/내부 결과 변조와 부분 저장 실패에서 appearance 완료 root0,
생장 전진은 내부 producer에서만 실행·DB/CLI0, WSL/원3root·소유 정리를 확인한다.
새 root의 무계산 reader/fresh→strict SDK/같은 UTC3D는 각각 후속 수용이다.
