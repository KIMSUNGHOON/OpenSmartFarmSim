# Coupled fractional shoot and leaf attachment, research v1

Bind the accepted fractional continuation CP to the actual selected stored stem,
preserving its development origin/initial organs/curves/anchors and the CP's coupled
air-temperature integral. This is an authored synthetic geometry calculation; it
does not approve a cultivar, biological emergence, stem carbon allocation or G0–G4/R2.

`describe_fractional_internode(point_context)` reads the current source and describes
the first certified threshold organ before leaf funding. Its deterministic ID uses
the original shoot/development/schedule IDs, sequence and threshold, following the
existing rational internode identity formula. No ODE, new leaf or old clock advance.
The birth coordinate is the certified crossed-side numerical upper bound, not a
claimed exact biological time. Preserve its interval and thermal overshoot.

`bind_fractional_crop(context, checkpoint, initial_bindings)` validates the current CP
with one current RHS. The explicit initial-link declaration binds the context, root
leaf/stem/initial-state hashes, common floor, complete ordered root leaf IDs, rights
and reviewer. Initial leaf ages are carried inputs; their past emergence is unknown.
Source/new point attachments must use their original recorded IDs and times. A missing
parent, future parent, altered mapping/source/time/floor or late rights/code drift holds.
Do not repair old placeholder IDs or silently map them onto arbitrary existing organs.
Corrections require new source/input versions, retaining old results and holds.

Project old organ ages from their actual selected age plus `(I_Ta - Tb*t)/86400`.
Create the first new organ from the selected source emergence profile at its exact
numerical birth, age zero and the explicitly requested/canonical initial length.
Later age uses `(I_Ta - I_Ta_birth - Tb*(t-t_birth))/86400`. Retain the numerical
threshold overshoot separately; never snap the shoot age to its threshold or fabricate
an old piecewise-constant clock. Use the existing canonical logistic length point.
Hold if a further threshold is pending; automatic repeated emergence remains future work.

Return the same CP's C_i/age/A, floor/LAI, phases/cursor/prefix/continuous and point
ledgers, actual original/new internode IDs/lengths and source/parameter/code receipts.
All leaves must bind before a combined result can be returned. The new internode's
carbon is not independently allocated; keep this scientific limitation explicit.
No DB/CLI/network/writes, old 22-degree forcing, past ODE or past clock advancement.
512 organs/leaves, 2MiB output and all existing lower byte/sample caps remain.

Acceptance: actual initial and newly created parent IDs, fractional birth/zero age,
shared Ta integral and preserved old state/anchors, explicit initial mapping and original
event links, same-time/later/horizon, duplicate/unknown/future/epoch/floor/source/rights
failures, independent age/length/area/C checks and fresh-process/resource preservation.
Immutable combined storage/readonly reader/SDK/same-state realistic3D are subsequent steps.
